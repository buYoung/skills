# Microsoft Store 시각 자산 디자인시스템

이 문서는 Windows 11 데스크톱용 MSIX 앱을 Microsoft Store에 등록할 때 사용하는 시각 자산의 역할, 제작 계약, 노출 조건, 디바이스 변형을 정의한다. 독자는 제품·브랜드·콘텐츠·스토어 등록 담당자다.

## 승인된 방향과 검증 상태

승인된 방향은 “제품의 정밀함을 우선하고 장식은 핵심 기능을 설명할 때만 사용한다”이다. 작은 앱 아이콘과 큰 갤러리 이미지에서 이 방향이 검증되었으므로, 모든 자산은 기능 이해와 신뢰 형성을 먼저 달성하고 장식적 요소는 기능을 설명하는 경우에만 허용한다.

검증된 대표 상황은 다음 두 가지다.

- 작은 앱 아이콘: 축소 상태에서도 식별 가능한 단일 형태와 선명한 대비를 유지한다.
- 큰 갤러리 이미지: 핵심 기능이 즉시 이해되며, Store의 오버레이·크롭을 견딘다.

## 범위

포함: 1:1 앱 타일 아이콘, 데스크톱 스크린샷, 트레일러, 16:9 Super hero art 및 디바이스 조건부 추가 artwork.

제외: 앱 이름, 설명, search terms, 가격, 인증 절차, 실제 PNG·영상·기타 바이너리 자산 제작.

## 소유 구조

Microsoft Store 전용 규칙은 [stores/microsoft-store.md](stores/microsoft-store.md)에 둔다. 이 파일은 방향, 범위, 검증 맥락과 소유 링크만 제공한다.

## 변경 원칙

Microsoft의 공식 규격·노출 조건이 변경되면 스토어 소유 문서의 출처와 확인일을 함께 갱신한다. 공식 요구사항과 이 제품의 디자인 권장사항을 구분해 기록하며, 지원하지 않는 디바이스용 자산은 업로드하지 않는다.
