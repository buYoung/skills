# 스크린샷과 미리보기

## 스크린샷

스크린샷은 실제 앱 UI를 보여 주는 증거다. 데스크톱 변형만 제공하며, 첫 이미지는 제품의 핵심 흐름을 가장 빠르게 이해하게 하는 화면으로 둔다. Microsoft Store에서는 디바이스 제품군별로 별도 자산을 연결할 수 있고 업로드 순서가 표시 순서가 된다.

스크린샷 내부에 추가 로고·아이콘·마케팅 메시지를 넣지 않는다. 중요한 화면과 텍스트는 이미지 상단 2/3에 두며, 하단 1/3에는 Store 텍스트 오버레이 가능성을 고려한다.

## 미리보기와 trailer

trailer는 실제 동작을 짧게 설명하는 선택 자산이다. 영상·thumbnail·title을 하나의 단위로 관리하고, 핵심 정보는 상·하단 크롭을 견디도록 중앙에 둔다. 접근성을 위해 closed captions와 audio description 변형을 함께 관리한다.

## 대표 검증

- 작은 상황: 아이콘 축소 검증 — 실루엣과 제품 식별이 장식 없이 유지된다.
- 큰 상황: 갤러리 이미지 검증 — 핵심 기능을 설명하는 실제 화면이 장식보다 먼저 읽힌다.

두 결과가 방향을 지지하지만, trailer를 실제로 제작·검증하는 일은 이 문서 범위가 아니다.
