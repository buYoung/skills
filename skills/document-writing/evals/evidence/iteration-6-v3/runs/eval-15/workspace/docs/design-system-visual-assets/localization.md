# 현지화와 변형

현재 대상은 Windows 11 데스크톱 MSIX 앱의 Store listing이다. 언어 목록과 지역 변형은 입력에 지정되지 않았으므로 확정하지 않는다.

Microsoft 공식 안내에 따르면 언어별 listing은 개별 페이지이며, 스크린샷과 caption은 각 언어에 맞춰 별도로 제공해야 한다. trailer는 기존 trailer를 다른 언어 listing에서 재사용할 수 있지만, 현지화된 caption·대체 텍스트의 필요성은 별도 검토한다.

오른쪽에서 왼쪽으로 쓰는 언어, 번역 확장, 문화적 적합성은 실제 대상 언어가 정해질 때 자산별로 검토한다. 지원 언어가 결정되기 전에는 새 이미지나 문구를 만들지 않는다.
