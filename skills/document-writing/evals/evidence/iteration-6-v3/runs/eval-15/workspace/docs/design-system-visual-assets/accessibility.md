# 접근성

- 스크린샷의 텍스트와 UI는 읽을 수 있어야 하며, 극도로 밝거나 어두운 색과 읽기를 방해하는 고대비 줄무늬를 피한다.
- 이미지에 텍스트를 넣는 경우 하단 오버레이와 겹치지 않게 하고, Microsoft가 명시한 대비 요구가 있는 artwork는 해당 값을 충족한다.
- trailer에는 closed captions와 audio description을 제공할 수 있도록 변형을 관리한다.
- 자산만으로 기능을 전달할 때 특정 색·장식에만 의미를 의존하지 않는다.

검증은 실제 축소 아이콘, 데스크톱 스크린샷, trailer thumbnail 및 자막 변형을 대상으로 한다. 앱의 전반적 접근성 인증이나 인증 절차는 범위에서 제외한다.
