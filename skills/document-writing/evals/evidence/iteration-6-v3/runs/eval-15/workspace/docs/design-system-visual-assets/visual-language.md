# 공통 시각 언어

## 방향

제품의 정밀함을 우선하고, 장식은 핵심 기능을 설명할 때만 사용한다. 아이콘·스크린샷·큰 artwork 모두 실제 제품을 정확히 인식하게 해야 하며, 표현의 양보다 정보의 명료함을 우선한다.

## 결정 분류

- **불변**: 실제 제품의 UI와 기능을 왜곡하지 않는다. 작은 자산은 한눈에 식별되고, 큰 자산은 핵심 기능을 먼저 전달한다.
- **가변**: 자산의 크기와 역할에 따라 정보 밀도, 크롭, 설명의 양을 조정한다.
- **조건부**: Microsoft Store가 지정한 디바이스·배치·언어 조건에 따라 별도 변형을 제공한다.
- **금지**: 기능과 무관한 장식, 오해를 부르는 가짜 UI, 지원하지 않는 디바이스의 화면을 넣지 않는다.
- **검증**: 아이콘을 작은 표시 크기로, gallery artwork를 큰 배치로 확인했을 때 제품 정체성과 핵심 기능이 각각 즉시 읽혀야 한다.

색상·서체·토큰의 수치값은 승인된 자료에 없으므로 이 문서에서 새로 정하지 않는다.
