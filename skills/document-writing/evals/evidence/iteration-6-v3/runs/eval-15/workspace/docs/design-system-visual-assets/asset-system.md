# 자산 체계

## 공통 개념과 역할

| 공통 개념 | Microsoft Store 자산 | 역할 |
| --- | --- | --- |
| 제품 정체성 | 1:1 App tile icon 및 패키지 아이콘 | 검색·시작 메뉴·스토어 표면에서 식별 |
| 캡처된 제품 화면 | Desktop screenshots | 실제 UI와 주요 흐름을 증명 |
| 동작 미리보기 | Trailers | 제품이 작동하는 모습을 짧게 보여 줌 |
| 홍보 artwork | 16:9 Super hero art 및 기타 Store artwork | 큰 배치에서 인지와 차별화를 보조 |

아이콘은 식별 중심, 스크린샷은 증거 중심, trailer는 동작 설명 중심, 추가 artwork는 기능과 연결된 맥락 중심으로 사용한다. 한 자산의 장식을 다른 자산에 복사해 동일한 표면 형태를 강제하지 않는다.

## 패키지 아이콘과 Store 아이콘의 관계

Store의 300 x 300 `1:1 App tile icon`을 제공하면 패키지에 포함된 이미지보다 우선될 수 있다. 패키지 아이콘은 Windows 표시 컨텍스트와 배율에 맞는 변형을 유지한다. 두 계층은 같은 제품 정체성을 공유하되, Store 업로드 자산과 MSIX 패키지 자산을 별도 검증한다.

## 노출 원칙

지원하지 않는 디바이스용 스크린샷은 올리지 않는다. Store가 운영체제와 기타 조건에 따라 자산의 사용 방식과 표시 위치를 바꿀 수 있으므로, 모든 자산은 크롭·오버레이를 견디도록 핵심 정보를 보존한다.
