# 전달과 버전 관리

## 전달 기준

자산별 파일 형식·픽셀·용량·개수와 디바이스 변형은 [stores/microsoft-store.md](stores/microsoft-store.md)의 공식 요구사항을 따른다. 원본과 내보낸 업로드 파일의 관계, 언어·스토어 변형 키, 검증일을 기록한다. 실제 자산 파일은 이 작업에서 만들지 않는다.

## 검증 기록

검증자는 다음을 확인한다.

1. 지원하지 않는 디바이스 자산이 섞이지 않았는가.
2. 파일 형식·크기·개수·픽셀 요구사항이 Store 파일에 맞는가.
3. 아이콘은 작은 크기에서 식별되고, 갤러리 이미지는 큰 크기에서 기능을 설명하는가.
4. 크롭·오버레이·현지화·접근성 변형이 손실 없이 연결되는가.

이 문서 세트의 방향 권위는 사용자 승인 문구와 두 대표 검증 사례이며, 스토어 규격의 권위는 2026-08-29에 확인한 Microsoft 공식 문서다.
