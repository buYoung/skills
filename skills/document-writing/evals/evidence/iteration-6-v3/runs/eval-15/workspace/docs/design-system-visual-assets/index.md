# Microsoft Store 시각 자산 디자인시스템

## 목적과 범위

Windows 11 데스크톱용 MSIX 앱을 Microsoft Store에 등록할 때 사용하는 시각 자산의 역할, 구성, 변형, 노출 조건을 정의한다. 이 세트는 실제 이미지·영상 제작물이 아니라 제작과 검수를 위한 기준 문서다. 앱 이름, 설명, search terms, 가격, 인증 절차는 범위에서 제외한다.

대상 독자는 디자인·콘텐츠·릴리스 담당자이며, 대상 스토어는 Microsoft Store, 대상 제품·디바이스는 Windows 11 데스크톱 MSIX 앱이다. Xbox, Holographic 및 게임 전용 자산은 현재 범위 밖이며, 지원이 추가되면 별도 조사한다.

## 승인된 방향과 근거

승인된 방향은 “제품의 정밀함을 우선하고 장식은 핵심 기능을 설명할 때만 사용한다”이다. 작은 앱 아이콘과 큰 갤러리 이미지에서 이 방향을 검증했으므로, 작은 크기에서는 식별성과 선명도를, 큰 크기에서는 기능을 설명하는 정보의 질을 우선한다.

## 대표 검증

- 작은 대표 상황: 앱 아이콘 — 축소되어도 제품 식별성이 유지되는지 확인했다.
- 큰 대표 상황: 갤러리 이미지 — 핵심 기능 설명이 장식보다 먼저 읽히는지 확인했다.

## 출처 우선순위

현재 Microsoft 공식 문서가 스토어 규격의 우선 출처다. 공통 방향과 팀 결정은 Microsoft의 운영 요구사항을 대체하지 않으며, 충돌 시 [stores/microsoft-store.md](stores/microsoft-store.md)의 적용 조건과 공식 출처를 우선 확인한다. 공식 문서는 2026-08-29에 열어 확인했다.
