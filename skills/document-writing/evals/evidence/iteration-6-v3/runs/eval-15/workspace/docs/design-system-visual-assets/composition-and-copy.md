# 구성과 시각 내부 문구

## 구성

모든 자산은 제품의 핵심 정보를 먼저 배치한다. Microsoft Store가 하단에 오버레이를 추가하거나 화면을 크롭할 수 있으므로 중요한 정보는 상단 2/3와 중앙에 보존한다. 과도한 빈 공간과 기능과 무관한 장식은 피한다.

## 문구 경계

이 문서는 일반 listing의 앱 이름, 설명, search terms를 다루지 않는다. 자산에 직접 붙는 스크린샷 caption과 trailer title은 Store의 업로드 필드로서만 관리하며, 제품 메시지 결정은 별도 범위다. 16:9 Super hero art에는 제품 제목이나 기타 텍스트를 넣지 않는다.

## 안전 영역

| 자산 | 안전 영역 원칙 |
| --- | --- |
| Desktop screenshot | 중요 화면·텍스트는 상단 2/3, 하단 오버레이 대비 |
| Trailer | 핵심 정보는 중앙, 상·하단 크롭 대비 |
| 16:9 Super hero art | 핵심 요소는 중앙·상단, 하단 1/3의 그라디언트 대비 |
