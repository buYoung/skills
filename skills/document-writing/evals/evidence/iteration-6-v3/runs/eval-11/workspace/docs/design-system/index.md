# Acme UI Design System

This is the canonical product UI design system for Acme Console.

## Scope and readers

This set is the shared reference for teams writing and reviewing Acme Console UI. It currently documents tokens, content guidance, accessibility guidance, and the existing integration boundary.

## Direction and validation status

No authoritative approval record for an upper-level visual direction or two contrasting representative validation situations is present in the supplied set. Content and accessibility guidance below is therefore a common working contract; visual-direction decisions that would require approval remain unresolved.

## Decision ownership

- Tokens and their exact values: [Tokens](tokens.md)
- Interface content and terminology: [Content](content.md)
- Cross-system accessibility: [Accessibility](accessibility.md)
- User-owned notes: [Team notes](team-notes.md)
- Established integration boundary: [Integration contract](integration-contract.md)

When sources conflict, preserve the exact token and integration contracts, then resolve content or accessibility conflicts with the owning document and record the unresolved decision rather than silently choosing.
