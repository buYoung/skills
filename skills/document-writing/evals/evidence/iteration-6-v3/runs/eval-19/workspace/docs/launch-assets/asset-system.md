# 자산 시스템

## 공통 개념

| 공통 개념 | 목적 | 상점별 변형 |
| --- | --- | --- |
| 제품 아이콘 | 작은 크기에서 제품을 식별 | 파일 형식·상한·업로드 위치 |
| 제품 화면 스크린샷 | 실제 기능과 정보 구조를 빠르게 이해 | 개수·비율·크기·캡션·순서 |
| 미리보기/배너 | 상점이 별도 노출면을 제공할 때 제품 인상을 보조 | 제공 여부·비율·파일 제한 |

공통 개념은 동일하게 유지하지만 모든 상점에서 같은 파일을 강제하지 않는다. 각 상점의 공식 자산명과 필수 여부는 상점 파일이 소유한다.

## 제품 화면의 진실성

스크린샷은 현재 출시 버전의 실제 UI를 사용한다. 기능을 더 좋아 보이게 하려고 존재하지 않는 상태, 홍보 문구, 외부 장식, 다른 플랫폼의 창 장식을 합성하지 않는다. 내용이 표시되는 앱은 빈 상태보다 기능을 이해시키는 실제 콘텐츠를 선택한다.

## 상점 매핑

- Flathub: AppStream의 아이콘·스크린샷 메타데이터로 연결한다. 자세한 조건은 [stores/flathub.md](stores/flathub.md)에 둔다.
- Snap Store: 그래픽 스토어용 아이콘·스크린샷과 선택적 배너를 구분한다. 자세한 조건은 [stores/snap-store.md](stores/snap-store.md)에 둔다.
