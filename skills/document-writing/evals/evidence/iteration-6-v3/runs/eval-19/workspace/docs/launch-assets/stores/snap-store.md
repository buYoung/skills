# Snap Store

## 범위와 적용성

Snap Store 그래픽 목록에 표시되는 아이콘·스크린샷·선택적 배너를 다룬다. 데스크톱 메뉴용 아이콘은 스토어 목록 아이콘과 별도이며, 이 문서는 스토어 시각 자산만 소유한다.

## 공식 안내와 확인 상태

Canonical이 운영하는 Snapcraft 공식 포럼의 “Store listing and branding” 안내를 2026-08-29에 열어 확인했다: https://forum.snapcraft.io/t/store-listing-and-branding/16397

페이지 본문은 2020년 게시된 안내이며 현재 페이지에 2024년 업로드 UI와 불일치한다는 보고가 남아 있다. 따라서 본문 수치는 준비 기준으로 기록하되, 업로드 직전 현재 Snap Store UI에서 다시 확인해야 한다.

## 아이콘·로고 (본문 안내)

- JPEG 또는 PNG
- 최대 512×512px
- 1:1
- 그래픽 스토어 프런트엔드용이며 데스크톱 메뉴·독 아이콘과 다름

현재 UI에 대해 페이지 댓글에서 PNG·JPEG·SVG, 40×40px 이상, 512×512px 이하, 1:1, 256kB라는 값이 보고됐지만, 이는 본문 규범과 충돌하는 사용자 보고이므로 확정 요구사항으로 승격하지 않는다.

## 스크린샷 (본문 안내)

- 최대 5개
- GIF·JPEG·PNG
- 480×480px 이상, 3840×2160px 이하
- 종횡비 1:2–2:1
- 2MB 이하
- 애니메이션은 1–30fps, 최대 40초
- 여러 플랫폼을 지원해도 Linux 워크스테이션에서 캡처

PNG가 JPEG보다 보기 좋다는 안내는 권장사항이며 제출 필수 조건과 구분한다. 스크린샷은 실제 제품 화면을 우선하고, 공통 방향에 따라 장식보다 판독성을 앞세운다.

## 배너 (선택적 노출)

본문은 배너를 추천 자산으로 설명하며, 추천 또는 선정 노출을 보장하지 않는다.

- JPEG 또는 PNG
- 최소 720×240px
- 스토어 최적화 권장 1920×640px 이상
- 최대 4320×1440px
- 3:1
- 2MB 이하

배너가 핵심 기능 이해를 방해하면 만들지 않거나 선택적 자산으로 취급한다.

## 미해결

아이콘의 SVG 허용, 최소 해상도, 256kB 용량 제한은 현재 UI 보고와 본문이 충돌한다. 업로드 담당자는 제출 시점의 Snap Store listing 화면에 표시된 제한을 확인하고, 그 결과를 이 파일에 갱신해야 한다. 본문과 UI 중 어느 값이 우선인지 공식 최신 문서가 명시되지 않아 여기서 선택하지 않는다.
