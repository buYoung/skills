# Flathub

## 범위와 적용성

Flathub의 그래픽 앱 목록에 노출되는 제품 아이콘과 AppStream 스크린샷을 다룬다. 제품이 데스크톱 앱인지 콘솔 앱인지에 따라 스크린샷 적용성이 달라질 수 있으므로, 콘솔 앱은 웹 검색 노출을 위해 스크린샷이 필요한 경우를 별도로 확인한다.

## 공식 안내와 확인 상태

Flathub 공식 문서를 2026-08-29에 열어 확인했다.

- 품질 안내: https://docs.flathub.org/docs/for-app-authors/metainfo-guidelines/quality-guidelines
- MetaInfo 안내: https://docs.flathub.org/docs/for-app-authors/metainfo-guidelines

## 아이콘

- SVG 또는 256×256px 이상 PNG
- 정사각형
- 캔버스를 과도하게 채우거나 지나치게 가늘게 만들지 않음
- 밝은 배경과 어두운 배경에서 대비 확보
- 작은 글자·미세한 디테일·내장 그림자·광택 금지

## 스크린샷

- 그래픽 앱은 MetaInfo에 하나 이상의 스크린샷을 제공해야 함
- 영어 스크린샷 최소 하나를 권장 기준으로 준비
- 중간 복잡도 앱은 3–6개가 적절한 범위로 안내됨
- 첫 번째 위치에 가장 좋은 화면 배치
- 언어 태그를 실제 언어와 일치시킴
- 앱 창과 네이티브 장식을 캡처하고 바탕화면·홍보 그래픽·임의 편집은 제외
- Linux에서 캡처
- 기본 설정을 사용하며, 창 크기는 1000×700px 이하(HiDPI 2000×1400px) 권장
- 모든 화면에 한 문장 캡션을 두고 마침표로 끝내지 않음

MetaInfo의 `image`는 웹의 직접 이미지 링크여야 하며, Git 저장소 이미지는 브랜치가 아닌 태그 또는 커밋 링크여야 한다. 이는 자산 파일 자체가 아니라 제출 메타데이터의 연결 조건이다.

## 검증

출시 전 MetaInfo에 아이콘과 스크린샷이 연결되고, 현재 UI를 반영하며, 대표 화면이 첫 위치에 있는지 확인한다. Flathub의 AppStream 검증 및 미러링 조건은 이 문서에 임의로 재정의하지 않고 공식 안내를 따른다.

## 미해결

제품의 앱 유형, 지원 언어, 실제 스크린샷 개수는 제공되지 않았다. 영어 최소 1개와 복잡도별 권장 범위를 적용할지는 출시팀이 제품 범위를 확인해 결정한다.
