# 전달과 버전 관리

## 출시 전 체크

1. 아이콘·스크린샷이 현재 출시 버전의 실제 화면인지 확인한다.
2. 작은 아이콘과 큰 스크린샷을 축소해 판독성을 확인한다.
3. 밝은 화면과 어두운 화면에서 대비를 확인한다.
4. 대상 상점 파일의 필수 형식·크기·개수·용량을 확인한다.
5. 상점별 미해결 요구사항이 남아 있으면 업로드 전에 공식 UI 또는 최신 안내로 재확인한다.

## 변경 시점

UI의 시각적 변경이 출시되는 경우 관련 스크린샷도 함께 갱신한다. Flathub 공식 안내도 화면의 현재 상태를 반영하고 UI 변경 시 스크린샷을 갱신하도록 권고한다. (2026-08-29 확인: https://docs.flathub.org/docs/for-app-authors/metainfo-guidelines/quality-guidelines)

## 책임 경계

이 문서는 자산의 규칙과 검증 기준만 관리한다. 실제 캡처·디자인·내보내기·업로드 도구, 담당자, 파일명 규칙은 별도 출시 운영 결정이 없으므로 여기서 발명하지 않는다.
