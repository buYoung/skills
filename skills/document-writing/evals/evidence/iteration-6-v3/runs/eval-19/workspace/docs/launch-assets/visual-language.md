# 공통 시각 언어

## 승인된 방향

출시 자산은 장식보다 실제 제품 화면의 판독성을 우선해, 사용자가 첫 화면에서 핵심 기능을 빠르게 이해하도록 한다. 표현은 차분하고 기술 제품답게 유지하며, 상점별 포맷 차이는 허용하되 제품 화면의 진실성을 바꾸지 않는다.

## 결정

| 분류 | 결정 |
| --- | --- |
| 불변 | 실제 제품 화면과 기능 이해가 모든 자산의 우선순위다. 아이콘은 작은 크기에서도 식별 가능해야 한다. |
| 불변 | 밝은 환경과 어두운 환경 모두에서 아이콘과 화면 요소가 분리되어 보여야 한다. |
| 가변 | 자산의 크기·비율·순서·정보 밀도는 역할과 상점 제약에 맞춰 바꾼다. |
| 조건부 | 상점이 요구하거나 허용하는 배너·애니메이션·브랜드 색상은 해당 상점 파일의 조건 안에서만 사용한다. |
| 금지 | 기능과 무관한 장식, 과도한 홍보 그래픽, 실제 UI를 오해하게 하는 합성·편집, 작은 아이콘 안의 읽기 어려운 문자. |
| 검증 | 작은 아이콘과 큰 스크린샷을 각각 축소해 식별성과 판독성을 확인하고, 밝은 화면과 어두운 화면에서 대비를 확인한다. |

## 색과 대비

배경과 아이콘이 비슷한 색으로 붙지 않도록 한다. Flathub는 밝은 테마와 어두운 테마에 서로 다른 주 브랜드 색을 두고, 어두운 변형은 더 어둡고 차분하게 만들 것을 안내한다. 색상값은 현재 브랜드 결정이 제공되지 않았으므로 이 문서에서 새로 정하지 않는다. (Flathub 공식 안내, 2026-08-29 확인: https://docs.flathub.org/docs/for-app-authors/metainfo-guidelines/quality-guidelines)

## 형태와 디테일

아이콘은 캔버스 가장자리에 닿을 정도로 크거나 투명 여백 때문에 지나치게 작지 않게 한다. 작은 크기에서 알아볼 수 있도록 미세한 디테일과 작은 글자를 피하고, 상점이 그림자를 적용할 수 있으므로 아이콘 자체에 그림자나 광택을 굽지 않는다. 이 원칙은 Flathub 공식 품질 안내와 승인된 소형 검증 결과에 근거한다.
