# 접근성과 판독성

## 필수 확인

- 아이콘을 작은 표시 크기로 축소해 형태와 핵심 대비가 유지되는지 확인한다.
- 밝은 화면과 어두운 화면에서 아이콘 가장자리와 주요 UI가 배경에 묻히지 않는지 확인한다.
- 스크린샷의 텍스트와 핵심 정보가 상점에서 축소되어도 읽히는지 확인한다.
- 기능을 전달하는 정보가 장식이나 색상에만 의존하지 않게 한다.
- 애니메이션 미리보기를 제공하는 경우 정지 이미지로도 핵심 기능을 이해할 수 있게 한다.

Flathub는 아이콘이 밝고 어두운 배경 모두에서 충분한 대비를 가져야 하며, 작은 크기에서 알아볼 수 있어야 한다고 안내한다. 승인된 밝은 화면/어두운 화면 검증은 이 공통 검증의 대표 사례다. (공식 안내, 2026-08-29 확인: https://docs.flathub.org/docs/for-app-authors/metainfo-guidelines/quality-guidelines)
