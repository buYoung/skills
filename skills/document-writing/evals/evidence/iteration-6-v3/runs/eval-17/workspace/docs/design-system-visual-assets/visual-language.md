# 공통 시각 언어

## 승인된 방향

친근한 협동 경험을 부드러운 형태로 표현하고, 팀이나 역할의 차이는 선명하게 구분한다. 표현은 플랫폼마다 달라질 수 있지만, 작은 크기와 동적인 상황에서도 제품의 실제 협동 경험을 먼저 읽을 수 있어야 한다.

## 결정

| 분류 | 규칙 |
| --- | --- |
| 불변 | 형태의 인상은 부드럽고 접근 가능해야 한다. 팀 구분은 빠르게 인지되어야 한다. 실제 제품 경험을 과장하거나 허위로 바꾸지 않는다. |
| 가변 | 자산의 밀도·크롭·정보량은 아이콘, capsule, screenshot, trailer의 역할과 노출 크기에 맞춘다. |
| 조건부 | 플랫폼이 정한 안전 영역, 포맷, 텍스트 제한, 비율을 우선 적용한다. 팀 구분을 위한 시각 신호는 해당 플랫폼에서 읽히는 방식으로 조정한다. |
| 금지 | 가격·할인·순위·수상·타 제품을 암시하는 배지나 문구를 시각 자산에 임의로 추가하지 않는다. 실제 제품에 없는 장면을 screenshot으로 제시하지 않는다. |
| 검증 | 작은 아이콘, 넓은 capsule, 정적 screenshot, trailer의 축소·일시정지·무음 상태에서 제품 식별, 팀 구분, 가독성이 유지되는지 확인한다. |

## 색과 형태의 역할

정확한 색상값은 제공된 근거가 없어 미정이다. 색은 팀 구분을 빠르게 지원하는 역할 관계로 정의하고, 단일 색상명이나 토큰은 별도 브랜드 근거가 생길 때 결정한다. 모서리와 실루엣은 부드러운 인상을 유지하되, 작은 아이콘에서 뭉개지지 않도록 단순화한다.

## 타이포그래피와 모션

정확한 서체·크기·모션 지속시간은 미정이다. 텍스트가 필요한 경우 플랫폼의 자산 규칙과 현지화 확장을 고려해 최소화한다. trailer에서는 협동의 상태 변화가 읽히는 움직임을 우선하고, 장식적 모션이 팀 구분을 가리지 않게 한다.
