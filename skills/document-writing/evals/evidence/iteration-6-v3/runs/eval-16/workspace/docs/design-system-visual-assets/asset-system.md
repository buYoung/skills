# 자산 시스템

## 공통 개념

| 공통 개념 | 기능 | Steam 매핑 |
|---|---|---|
| 제품 식별 자산 | 이름과 제품의 첫 인상을 전달 | Header Capsule, Small Capsule, Main Capsule, Vertical Capsule |
| 실제 플레이 증거 | 게임을 어떻게 플레이하는지 보여줌 | Screenshots |
| 시간 기반 플레이 증거 | 움직임·전투 흐름을 보여줌 | Trailers |
| 영상 대표 프레임 | 영상 로딩 전·목록에서 영상 식별 | Poster image, Thumbnail image |

공통 방향은 자산마다 동일한 대비·흐름·판독성 우선순위를 유지한다. 다만 표시 크기, 정지/동영상 여부, 노출 위치에 따라 정보 밀도와 브랜드 강조를 바꾼다. Steam 고유의 required, dimensions, placement는 [stores/steam.md](stores/steam.md)가 소유한다.

## 자산 관계

상점 페이지에서는 trailer의 첫 두 개 유효 영상이 screenshot보다 먼저 노출되고, 나머지 trailer는 screenshot 목록 뒤에 나타난다. Steam은 첫 번째로 표시되는 video를 기반으로 6초 microtrailer를 자동 생성하므로, 첫 trailer가 핵심 전투 흐름을 대표해야 한다. 세부 노출과 업로드 규칙은 [screenshots-and-previews.md](screenshots-and-previews.md)를 따른다.
