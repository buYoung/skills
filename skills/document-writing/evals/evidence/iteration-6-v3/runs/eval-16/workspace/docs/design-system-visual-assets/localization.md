# 현지화

Steam capsule에 추가 문구를 넣는 경우 지원 언어와 동일한 언어 집합으로 현지화한다. Trailer는 언어별 영상을 지정할 수 있고, 다국어 구성에서는 Base video를 English trailer로 설정한다. 국가별 등급 영상은 ISO 3166-1 alpha-2 코드로 노출 국가를 제한할 수 있다.

Screenshot의 localized version은 기존 screenshot thumbnail에 대체 버전으로 업로드한다. 언어 접미사는 UI가 언어를 추정하는 힌트로 사용할 수 있지만, 파일명 관례를 필수 규격으로 간주하지 않는다.

확인되지 않은 지역별 변형이나 번역 문구는 이 문서에서 새로 정하지 않는다.
