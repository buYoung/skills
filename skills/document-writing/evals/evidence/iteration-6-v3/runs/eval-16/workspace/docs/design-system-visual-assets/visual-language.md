# 공통 시각 언어

## 승인된 방향

빠른 전투의 긴장감은 높은 대비와 대각선 흐름으로 드러내되, 모든 크기와 재생 조건에서 실제 플레이 정보가 먼저 읽혀야 한다. 표현의 강도는 자산의 역할과 표시 크기에 따라 달라지고, 판독성과 실제 제품 충실성은 변하지 않는다.

## 결정 분류

### 불변

- 실제 게임플레이의 핵심 상황과 조작 결과를 흐리지 않는다.
- 높은 대비는 전투의 상태·방향·위험을 구분하는 데 기여해야 한다.
- 대각선 흐름은 시선을 유도하되 UI, 캐릭터 식별, 목표를 가리지 않는다.
- 로고와 제품명은 해당 자산의 표시 크기에서 읽혀야 한다.

### 가변

- 작은 capsule은 로고와 단순한 핵심 실루엣에 시각적 무게를 집중한다.
- 큰 hero나 trailer는 전투의 방향성과 시간적 전개를 더 풍부하게 보여줄 수 있다.
- screenshot은 장식보다 실제 플레이 정보의 밀도와 다양성을 우선한다.

### 조건부

- Steam의 store capsule은 게임 artwork, 게임 이름, 공식 subtitle 범위 안에서 구성한다. 업데이트·시즌 이벤트 문구가 필요하면 Artwork Override를 사용하고 기간과 현지화 조건을 따른다.
- Library Hero는 텍스트 없이 artwork만 사용하며, critical content는 공식 safe area 안에 둔다.

### 금지

- capsule에 review score, award, 할인 문구, 다른 제품 홍보, 기타 임의 문구를 넣지 않는다.
- 실제 플레이를 보여줘야 하는 screenshot에 concept art, pre-rendered cinematic still, marketing copy를 넣지 않는다.
- 실제 이미지나 영상을 이 문서 작업에서 생성하지 않는다.

### 검증

- 작은 capsule을 축소해도 로고와 핵심 형상이 즉시 식별되는가.
- 큰 hero에서 대각선 흐름이 UI·목표·캐릭터 얼굴을 가리지 않는가.
- 정적 screenshot과 trailer을 무음·축소 조건에서 보아 실제 플레이가 무엇인지 이해되는가.
