# 구성과 자산 내부 문구

## 계층

작은 capsule은 로고와 제품 식별을 최우선으로 두고, 큰 capsule·hero는 전투의 방향성과 핵심 형상을 확장한다. screenshot과 trailer은 실제 플레이 정보가 장식적 대비보다 앞선다.

## Steam 문구 규칙

Store capsule의 기본 콘텐츠는 game artwork, game name, official subtitle뿐이다. review score, award, discount copy, 다른 제품 홍보, 기타 miscellaneous text는 금지된다. 업데이트·seasonal event·battle pass·DLC 등 새 콘텐츠를 설명하는 추가 문구만 Artwork Override로 허용되며, 최대 1개월과 게임이 지원하는 동일 언어 집합으로 현지화해야 한다.

Screenshot에는 marketing copy나 written product description을 직접 삽입하지 않는다. Library Hero에는 어떤 단어도 넣지 않는다.

## 안전 영역

Library Hero의 3840×1240 template에서 공식 safe area는 860×380이다. artwork는 전체를 채우되 얼굴·목표·식별에 중요한 요소는 safe area 안에 둔다. 이 규칙은 Steam Library에만 조건부 적용된다.
