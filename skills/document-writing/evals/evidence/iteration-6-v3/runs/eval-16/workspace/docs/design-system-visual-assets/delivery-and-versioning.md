# 납품과 버전 관리

## 납품 검증

- Store capsule의 현재 Steam 규격은 [stores/steam.md](stores/steam.md)와 현재 공식 템플릿을 대조한다.
- Trailer는 인코딩이 끝난 뒤 release를 진행한다. Steam 문서상 처리 중에는 release할 수 없다.
- 실제 플레이 screenshot 최소 수량과 모든 영상·이미지 format, ratio, size를 업로드 전 검사한다.
- Artwork Override는 임시 문구·기간·현지화 조건을 기록하고 만료 뒤 base capsule로 돌아가는지 확인한다.

## 변경 기록

Steamworks 규격은 변경될 수 있으므로 배포 시 공식 원문을 다시 확인한다. 2024년 8월 Steam은 대부분 capsule의 더 큰 크기를 받기 시작했고 이전 크기는 더 이상 허용되지 않는다고 공지했다. 따라서 저장된 export preset보다 현재 공식 템플릿을 우선한다.

이 문서에는 실제 source filename, owner, release status를 발명하지 않는다. 프로젝트가 정하면 해당 값을 별도 기록한다.
