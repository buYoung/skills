# 완료

Steam 게임 상점페이지용 시각 자산 디자인 시스템 문서 세트를 작성했습니다. 승인된 방향과 제공된 검증 결과를 공통 원칙으로 기록하고, Steamworks 공식 자료를 live-open하여 Steam의 실제 자산 명칭·역할·필수 여부·규격·콘텐츠 제한·노출 관계를 별도 storefront 문서에 정리했습니다.

생성된 문서:

- `docs/design-system-visual-assets/index.md`
- `docs/design-system-visual-assets/visual-language.md`
- `docs/design-system-visual-assets/asset-system.md`
- `docs/design-system-visual-assets/screenshots-and-previews.md`
- `docs/design-system-visual-assets/composition-and-copy.md`
- `docs/design-system-visual-assets/localization.md`
- `docs/design-system-visual-assets/accessibility.md`
- `docs/design-system-visual-assets/delivery-and-versioning.md`
- `docs/design-system-visual-assets/stores/steam.md`

`feature graphic`은 Steam 명칭으로 사용하지 않았고, 실제 이미지나 영상은 생성하지 않았습니다. 조사 근거는 [Steamworks Store Graphical Assets](https://partner.steamgames.com/doc/store/assets/standard?l=english), [Graphical Asset Rules](https://partner.steamgames.com/doc/store/assets/rules?l=english), [Trailers](https://partner.steamgames.com/doc/store/trailer), [Library Assets](https://partner.steamgames.com/doc/store/assets/libraryassets?l=english&language=english)입니다.

검증 상태: 승인된 방향과 두 가지 대비되는 대표 상황(작은 capsule/큰 hero, 정적 screenshot/trailer)이 제공되어 문서화 gate를 충족했습니다. 문서 작성 중 실제 자산 제작·렌더링 검증은 수행하지 않았습니다.
