# 시각 언어

## 공통 방향

실제 제품 장면이 시선의 중심이어야 하며, 장식은 한 가지 청록색 강조로 제한한다. 모든 listing 자산은 이 관계를 유지하되, 자산의 크기와 역할에 따라 정보 밀도와 구성은 달라질 수 있다.

## 결정 분류

| 분류 | 결정 |
| --- | --- |
| 불변 | 실제 제품 장면을 중심에 둔다. |
| 불변 | 장식 색상은 한 가지 청록색 강조로 제한한다. |
| 가변 | discovery card와 screenshot은 자산 역할과 크기에 맞춰 정보 밀도와 배치를 조정한다. |
| 조건부 | preview를 포함할 때는 silent preview의 시간과 시작 장면 규칙을 따른다. |
| 금지 | setup 또는 account-creation 화면을 제품 screenshot의 대표 장면으로 사용하지 않는다. |
| 검증 | 작은 discovery card와 큰 screenshot, 정적 이미지와 silent preview에서 제품 중심성과 단일 청록색 강조가 유지되는지 확인한다. |

가이드에는 서체, 배경, device frame, 정확한 청록색 값, 장식의 형태에 관한 결정이 없으므로 이 문서에서 추가로 정하지 않는다.

## 검수 기준

- 실제 제품 장면이 장식보다 먼저 인식된다.
- 장식 색상 역할이 청록색 하나로 제한된다.
- 자산의 역할과 크기에 따라 배치는 달라도 공통 방향은 유지된다.
