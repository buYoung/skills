# 전달과 버전 관리

## 자산 패키지

각 전달본은 앱 제품 버전, 자산 유형, 기기 유형, locale, 생성일을 식별할 수 있어야 한다. 실제 저장소의 도구·소유자·파일 확장자는 현재 요청에 공급되지 않았으므로 임의로 정하지 않는다.

## 변경 규칙

- 제품 UI가 바뀌면 해당 화면을 보여주는 아이콘·스크린샷·preview·feature graphic의 약속을 함께 재검토한다.
- 강조색, 제품 화면 중심, 절제된 장식이라는 승인 방향을 바꾸는 변경은 브랜드 책임자 재승인과 대표 상황 재검증이 필요하다.
- 좁은 화면과 정보량이 많은 화면을 포함한 두 대표 상황을 릴리스 전에 다시 확인한다.

## 전달 검수

1. 공통 방향과 자산 간 역할 관계를 확인한다.
2. 실제 제품 버전과 캡처가 일치하는지 확인한다.
3. locale·기기 변형의 파일과 문구가 올바르게 연결되는지 확인한다.
4. Google Play 공식 요구사항을 [stores/google-play.md](stores/google-play.md) 기준으로 검수한다.
5. 이전 자산을 폐기할 때 새 자산이 모든 대상 배치에 연결되었는지 확인한다.

## 미해결 결정

- 지원 기기 유형, 제품 분류(앱 또는 게임), 지원 locale 목록, 실제 소스 파일 형식·명명 규칙·소유자는 제공되지 않았다. 해당 값은 릴리스 담당자가 확정해야 한다.
