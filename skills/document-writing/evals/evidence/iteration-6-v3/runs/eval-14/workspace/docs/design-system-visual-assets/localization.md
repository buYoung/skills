# 현지화

## 기본 규칙

지원 언어별로 자산 내 문구와 브랜딩 문구를 별도 검토한다. 번역은 의미·기능·제품 상태를 유지하되, 언어별 길이 증가를 흡수하도록 구성과 캡션을 조정한다.

## RTL과 지역 변형

오른쪽에서 왼쪽으로 읽는 언어는 순서, 정렬, 방향성이 의미를 갖는 UI를 RTL에 맞게 검토한다. 단순히 문구만 뒤집어 실제 제품 화면의 방향성과 어긋나지 않게 한다. 지역별 색·이미지·문화적 적합성은 승인된 방향을 유지하는 범위에서 검토하고, 예외는 해당 locale과 함께 기록한다.

## 검수와 fallback

- 번역된 문구가 안전 영역을 넘지 않는지 확인한다.
- 자산이 없는 locale은 승인된 기본 언어 자산을 fallback으로 사용하되, 제품 화면과 노출 언어가 불일치하는 경우 릴리스 전에 결정한다.
- 모든 언어 버전에도 동일한 Google Play 정책과 시각 자산 제한이 적용된다.
