# 자산 시스템

## 공통 개념과 관계

| 자산 | 역할 | 다른 자산과의 관계 |
|---|---|---|
| 앱 아이콘 | 작은 크기에서 제품을 식별하는 표지 | feature graphic과 제품 UI의 색·스타일 단서를 공유하되 복제하지 않는다. |
| 스크린샷 | 실제 제품의 기능, 화면, 사용 흐름을 증명 | 아이콘의 인식을 확장하고 preview의 핵심 장면을 정적으로 보강한다. |
| preview video | 시간축으로 제품의 가치와 사용 경험을 보여주는 미리보기 | 스크린샷보다 먼저 노출될 수 있으며, 실제 제품 화면을 중심으로 한다. |
| feature graphic | 제품 경험을 한 장의 넓은 장면으로 전달하고 preview의 표지 역할을 지원 | 아이콘과 중복되는 로고 표현을 피하고, 스크린샷의 세부 UI를 대신하지 않는다. |

## 공통 소스

제품의 현재 UI 캡처와 브랜드 승인 방향이 공통 소스다. 자산별 최종 파일, 캡처 시점, 제품 버전, 현지화 버전은 [delivery-and-versioning.md](delivery-and-versioning.md)에 연결한다.

## 적용 원칙

- **불변:** 실제 제품 경험 중심, 절제된 장식, 한 가지 선명한 강조색.
- **가변:** 자산의 크기·밀도·순서·시간축은 역할과 노출 맥락에 맞춘다.
- **조건부:** Google Play의 공식 명칭·규격·개수·배치는 [stores/google-play.md](stores/google-play.md)가 소유한다.
- **검증:** 네 자산을 함께 놓았을 때 제품 화면이 주인공이고, 각 자산이 서로 다른 질문(무엇인가/무엇을 하는가/어떻게 느껴지는가/왜 관심을 가져야 하는가)에 답해야 한다.
