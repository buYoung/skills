# 스크린샷과 preview

## 화면 선택

스크린샷은 실제 제품의 핵심 기능과 콘텐츠를 보여주는 화면을 선택한다. 첫 세 장은 제품 UI와 핵심 흐름의 이해를 우선하고, 정보가 많은 화면은 계층을 정리하되 실제 경험을 삭제하거나 과장하지 않는다.

## 순서와 서사

1. 사용자가 제품을 무엇으로 인식하는지 보여주는 진입 화면
2. 핵심 기능이 실제로 작동하는 화면
3. 정보가 많은 상황에서도 결과를 이해할 수 있는 화면
4. 차별적 기능 또는 다음 행동을 설명하는 보조 화면

순서는 제품 버전과 현지화 버전에 걸쳐 같은 의미를 유지한다. Google Play에서 preview video가 있으면 스크린샷보다 앞에 표시될 수 있으므로 preview의 첫 장면과 첫 스크린샷이 중복된 약속을 하지 않게 한다.

## 정적 자산과 움직이는 preview

- **정적:** 한눈에 핵심 정보를 전달하며, 제품 UI가 주인공이다.
- **움직임:** 핵심 제품 경험을 가능한 이른 시점에 보여주고, 전환·강조색·문구는 이해를 돕는 만큼만 사용한다.
- **관계:** preview는 스크린샷의 단순 슬라이드쇼가 아니라 흐름을 증명하는 시간 기반 자산이다. 실제 화면과 최종 제품 동작을 사용한다.

## 검증

작은 아이콘, 정보량이 많은 스크린샷, 정적 이미지와 움직이는 preview를 함께 비교해 공통 방향과 각 역할의 차이를 확인한다. Google Play별 형식과 개수는 [stores/google-play.md](stores/google-play.md)에서 확인한다.
