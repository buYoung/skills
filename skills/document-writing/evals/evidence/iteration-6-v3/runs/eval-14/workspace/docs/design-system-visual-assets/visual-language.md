# 시각 언어

## 승인된 방향

실제 제품 화면이 주인공이고 장식은 절제한다. 한 가지 선명한 강조색을 핵심 전환점과 브랜드 인식에 사용해 진취적인 인상을 만든다. 이 방향은 브랜드 책임자가 승인했다.

## 결정 분류

### 불변

- 실제 제품 화면 또는 실제 제품 경험을 시각적 증거의 중심에 둔다.
- 강조색은 한 가지로 수렴하고, 기능·상태·브랜드 인식에 의미 있게 사용한다.
- 장식은 정보 전달을 보조하는 수준으로 제한한다.
- 아이콘, 정적 자산, 움직이는 preview는 서로 비슷하거나 보완적인 색·스타일을 유지한다.

### 가변

- 아이콘은 작은 크기에서 식별성이 우선이고, 스크린샷은 정보 밀도가 높아도 핵심 흐름을 읽을 수 있어야 한다.
- feature graphic은 제품 경험을 암시하는 보조적 장면을 허용하되, 세부 묘사보다 중심 메시지를 우선한다.
- preview video는 시간축을 사용해 핵심 경험을 빠르게 보여주며, 정적 자산과 동일한 장면을 기계적으로 복제하지 않는다.

### 조건부

- Google Play의 기기 유형, 배치, 잘림 영역, 형식 제약은 [stores/google-play.md](stores/google-play.md)에 따른다.
- 제품 유형(앱/게임)이나 지원 기기 유형이 확정되면 해당 조건만 적용한다. 현재 요청만으로 확정되지 않은 가지는 임의로 선택하지 않는다.

### 금지

- 제품에 없는 기능을 보여주거나 실제 UI를 오해하게 만드는 합성.
- 작은 크기에서도 읽히지 않는 장식적 세부사항의 과도한 사용.
- 강조색을 여러 경쟁 색으로 분산해 계층을 흐리는 표현.
- 순위, 수상, 가격·할인, 매장 배지처럼 제품 경험과 무관한 홍보 신호를 자산에 넣는 것.

## 검증 기준

- 작은 앱 아이콘만 보아도 형태와 강조색이 식별된다.
- 정보량이 많은 스크린샷에서도 실제 UI와 핵심 메시지가 장식보다 먼저 읽힌다.
- 정적 자산과 preview의 첫 인상에서 같은 제품이라는 연결이 보인다.
- 강조색이 핵심 지점을 가리키되 본문 대비와 가독성을 해치지 않는다.
