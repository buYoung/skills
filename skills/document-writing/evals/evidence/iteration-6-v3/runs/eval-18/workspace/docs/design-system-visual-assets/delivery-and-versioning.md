# 전달과 버전 관리

## 전달 원칙

공통 방향 검토 기록과 스토어별 제출 규격을 분리해 관리한다. 아트워크·로고·동영상·커버 이미지는 사용처와 로케일을 식별할 수 있는 이름으로 묶되, 실제 파일명·포맷·용량·업로드 그룹은 공식 요구사항 확인 후 확정한다.

## 검증 기록

현재 확인된 대표 검증은 작은 표지, 큰 홍보 이미지, 정적 이미지, 움직임이다. 다음 제출 전에는 Epic Developer Portal에서 최신 자산 목록, 필수 여부, 규격, 파일 제한, 로케일·반응형 예외를 다시 확인하고 이 문서의 [스토어 파일](stores/epic-games-store.md)에 출처와 확인일을 갱신한다.

## 미해결 변경

공식 요구사항이 승인된 공통 방향과 충돌하면 공통 방향을 임의로 바꾸지 말고, 해당 배치의 조건부 적응으로 기록한 뒤 대표 검증을 반복한다.
