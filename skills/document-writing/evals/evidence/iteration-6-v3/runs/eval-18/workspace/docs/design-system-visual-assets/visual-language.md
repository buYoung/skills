# 공통 시각 언어

## 승인된 방향

어두운 환경 안에서 주제가 읽히는 강한 실루엣을 우선하고, 한 가지 따뜻한 강조색을 제한적으로 사용해 탐험의 긴장감을 만든다. 작은 표지와 큰 홍보 이미지, 정적 이미지와 움직임에서도 이 관계가 유지되는지가 검증 기준이다.

## 결정

| 분류 | 규칙 |
| --- | --- |
| 불변 | 어두운 환경, 강한 실루엣, 하나의 따뜻한 강조 역할, 탐험의 긴장감이라는 관계를 유지한다. |
| 가변 | 자산의 기능과 표시 크기에 따라 피사체 규모, 정보 밀도, 크롭, 움직임의 양을 조정한다. |
| 조건부 | Epic의 배치가 오버레이·반응형·로케일별 공간을 요구하면 피사체와 강조색의 위치를 그 공간에 맞춘다. 공식 조건은 [스토어 문서](stores/epic-games-store.md)에 기록한다. |
| 금지 | 작은 크기에서 읽히지 않는 세부 묘사, 강조색의 다중 경쟁, UI나 오버레이를 가리는 프레임·장식은 사용하지 않는다. 단, 플랫폼 요구사항이 별도로 확인되면 그 조건을 우선 검토한다. |
| 검증 | 축소했을 때 실루엣과 핵심 피사체가 즉시 구분되고, 따뜻한 강조색이 하나의 시선 경로를 만들며, 정적·동적 버전의 인상이 같은 방향을 가리켜야 한다. |

## 적용 해석

공통성은 동일한 표면을 복제하는 것이 아니라 명암 관계와 강조 역할을 보존하는 것이다. 작은 표지는 식별성을, 큰 홍보 이미지는 탐험의 분위기와 공간감을 우선한다. 움직임은 실루엣을 흐리거나 강조색을 여러 경쟁점으로 만들지 않는 범위에서 긴장감을 강화한다.
