# 자산 시스템

## 공통 자산 개념

| 개념 | 역할 | 방향 적용 |
| --- | --- | --- |
| 작은 표지 | 목록·탐색에서 제품을 식별하는 대표 자산 | 실루엣과 따뜻한 강조색의 대비를 단순화해 축소 식별성을 확보한다. |
| 큰 홍보 이미지 | 상점의 주요 노출에서 세계와 탐험의 긴장감을 전달하는 자산 | 더 넓은 공간과 깊이를 허용하되 핵심 실루엣과 강조색의 단일 초점을 유지한다. |
| 정적 이미지 | 고정된 장면·제품 상태를 전달하는 자산 | 실제 게임 또는 제품의 상태를 과장 없이 보여준다. |
| 움직임 | 장면의 변화나 긴장감을 보강하는 자산 | 움직임이 실루엣의 판독성과 강조색의 역할을 훼손하지 않아야 한다. |

자산별 공식 이름·필수 여부·규격·배치는 [Epic Games Store 문서](stores/epic-games-store.md)의 소유 범위다. 이 문서는 서로 다른 스토어의 수치를 공통 규칙으로 복제하지 않는다.

## 관계

작은 표지는 큰 홍보 이미지의 축소판이 아니다. 표지는 식별 가능한 실루엣과 단일 강조 초점을 남기고, 큰 이미지는 같은 방향을 더 넓은 공간·분위기로 확장한다. 정적 버전은 기준 프레임을 제공하고, 움직임 버전은 그 기준을 벗어나지 않는 변화를 제공한다.
