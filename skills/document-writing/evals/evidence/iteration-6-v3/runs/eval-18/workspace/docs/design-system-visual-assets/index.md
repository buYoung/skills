# Epic Games Store 시각 자산 디자인 시스템

이 문서는 Epic Games Store 상점 페이지에서 게임의 시각 자산을 일관되게 설계·검토하기 위한 기준이다. 승인된 방향은 “어두운 환경에서 강한 실루엣과 한 가지 따뜻한 강조색으로 탐험의 긴장감을 전달한다”이며, 작은 표지와 큰 홍보 이미지, 정적 이미지와 움직임에서 검증됐다.

## 범위와 독자

대상은 Epic Games Store용 게임 상점 시각 자산을 만드는 아트·마케팅·로컬라이제이션·퍼블리싱 담당자다. 공통 시각 언어와 자산 간 관계를 정의하며, 실제 이미지·영상 제작은 포함하지 않는다. Epic Developer Portal의 현재 제출 규격은 별도 확인이 필요하다.

## 방향의 근거와 검증 상태

- 방향 권위: 사용자 승인 문장.
- 대표 검증: 작은 표지와 큰 홍보 이미지, 정적 이미지와 움직임에서 방향이 검증되었다는 사용자 제공 기록.
- 성숙도: 디자인 시스템 문서화.
- 외부 확인일: 2026-08-29에 Epic 공식 배포 안내, 공식 Marcom 가이드 PDF, 공식 요구사항 URL을 확인했다.
- 제한: 공식 publisher portal의 asset specification 페이지는 현재 실행 환경에서 접근하지 못했다. 따라서 일반 Product Details Page(PDP)의 최신 자산명·필수 여부·규격은 미확인이다.

## 우선순위

사용자 승인 방향과 검증 결과가 공통 시각 원칙의 기준이다. Epic 공식 요구사항이 특정 배치·파일·로케일에 적용되면 해당 조건이 자산 전달 규칙을 우선한다. 충돌을 해결할 공식 근거가 없으면 [Epic Games Store 문서](stores/epic-games-store.md)의 미해결 항목으로 남긴다.
