# 공통 패턴

## 업무 정보와 핵심 행동

업무 정보가 조밀해져도 핵심 행동은 정보 위계에서 먼저 인지되어야 한다. 세부 정보와 보조 행동은 핵심 행동을 가리지 않는 범위에서 내용과 복잡도에 따라 배치한다.

## 대표 상황

- 단순 폼: 사용자가 입력을 완료하고 다음 행동을 바로 찾을 수 있어야 한다.
- 복잡한 표: 정보량이 많아도 주요 행위와 표의 구조를 구분할 수 있어야 한다.

## 입력 적응

키보드와 터치는 동일한 상위 방향을 공유하지만 입력 방식에 맞는 상호작용 차이를 허용한다. 구체적인 웹 차이는 [웹 플랫폼 규칙](platforms/web.md)에 둔다. 모바일 차이는 플랫폼 범위 확정 후 작성한다.

## 검증

단순 폼과 복잡한 표를 각각 키보드와 터치로 대표 검증한다. 핵심 행동의 발견 가능성, 정보 위계, 입력 흐름이 유지되지 않으면 공통 패턴 또는 플랫폼 적응의 소유 수준을 먼저 확인한다.
