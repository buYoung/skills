# 거버넌스

## 현재 상태

- 방향: 승인됨
- 대표 검증: 단순 폼, 복잡한 표, 키보드, 터치에서 완료됨
- 변경 시 기준: 조밀한 업무 정보에서 핵심 행동이 먼저 보이는지와 차분한 도구라는 방향을 다시 확인한다.

## 검증과 변경

방향을 바꾸거나 공통 규칙을 추가할 때는 서로 대비되는 업무 상황을 포함해 검증한다. 플랫폼 차이는 공통 규칙에 흡수하지 않고 해당 플랫폼 소유 파일에서 갱신한다. 모바일 범위가 결정되면 `index.md`의 미결 상태를 갱신하고 구체 플랫폼 파일을 추가한다.

## 미결 결정

모바일이 iOS와 Android를 모두 가리키는지, 아니면 제품 내부의 단일 분류 이름인지 정해지지 않았다. 이 결정이 확정되기 전에는 모바일 적응 규칙을 만들지 않는다.
