# 공통 접근성

## 방향과 접근성

접근성은 핵심 행동이 먼저 보이고 조밀한 업무 정보를 이해할 수 있다는 방향을 보정하는 공통 계약이다. 키보드와 터치 입력 모두에서 업무 흐름과 핵심 행동의 식별 가능성을 확인한다.

## 결정 분류

- 불변: 입력 방식과 관계없이 핵심 행동과 정보 위계가 이해되어야 한다.
- 조건부: 플랫폼별 입력·탐색 접근성 차이는 해당 플랫폼 파일에서 관리한다.
- 검증: 키보드와 터치 대표 검증에서 핵심 행동에 도달하고 조작할 수 있는지 확인한다.

구체적인 대비, 크기, 의미론, 포커스, 확대, 모션 값은 승인된 근거가 없으므로 이 문서에서 새로 정하지 않는다.
