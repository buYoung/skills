# Content

## Voice

Interface language should be concise, calm, and precise. Labels and instructions expose the user's next action or the data relationship before adding friendly tone.

## Contextual adaptation

Web administrator content may support scanning with compact labels and clear column relationships. iOS completion content should keep the final action and resulting state explicit in a short flow. Friendly wording must not obscure whether an action is complete, pending, blocked, or reversible.
