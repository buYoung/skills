# Web platform adaptation

## Scope

This file covers the web administrator product. It preserves the common direction in [foundations.md](../foundations.md) while documenting web-specific density and interaction context.

## Conditional rules

- A dense data table may use compact presentation when comparison and scanning are primary.
- Column relationships, sorting or filtering affordances, and row states must remain visually and semantically distinguishable.
- Keyboard access and visible focus are required for interactive table controls and navigation.
- Motion must not interrupt scanning or be required to understand a row state.

## Contextual variation

The web table may be denser than the iOS completion flow. This is a task adaptation, not a departure from calm precision or visible hierarchy. The large header logo may support product orientation, while feature icons remain function-led.

## Unresolved platform values

Breakpoints, density measurements, focus styling values, and browser support targets were not supplied and remain implementation decisions.
