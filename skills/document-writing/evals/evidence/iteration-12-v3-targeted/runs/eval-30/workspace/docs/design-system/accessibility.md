# Accessibility

## Cross-system requirements

Hierarchy, action, status, and icon meaning must not depend on color, motion, or logo presence alone. Provide text or semantic alternatives for feature icons and expose state through accessible names and descriptions.

## Scaling and input

The system must remain understandable when text or display size changes. Keyboard and alternative input must reach web actions; iOS interactions must remain available through platform accessibility APIs and supported input behavior.

## Motion

Motion is optional reinforcement. Reduced-motion settings must remove or reduce nonessential movement without removing state or completion information.

## Verification

Check the dense table at increased text size, the short iOS completion flow with accessibility services, the large header logo with an appropriate accessible name, and the 16px feature icon with a semantic label or adjacent text. Exact contrast thresholds and target-size values remain to be supplied by the governing accessibility standard for implementation.
