# 스토어 자산 체계

## 공통 자산 개념

| 개념 | Orbit Notes 적용 |
| --- | --- |
| 제품 식별 | `Orbit Notes`와 `생각을 놓치지 마세요`를 핵심 식별 언어로 사용 |
| 프로모션 아트워크 | [orbit-notes-feature-graphic.png](orbit-notes-feature-graphic.png) |
| 실제 제품 화면 | 미제공. 스크린샷 제작·승인 전 확인 필요 |
| 동영상 미리보기 | 미제공. 동영상이 있다면 feature graphic이 커버 이미지로 사용될 수 있음 |

## 자산 간 관계

feature graphic은 앱 아이콘과 나란히 노출될 수 있으므로 아이콘을 그대로 반복하지 않고, 브랜드 확장 역할을 한다. 스크린샷은 실제 앱 경험을 보여줘야 하므로 추상 feature graphic을 스크린샷의 대체물로 사용하지 않는다.
