# 시각 언어

## 브랜드 연속성

Orbit Notes의 모든 Google Play 시각 자료는 `#2457D6`를 주 색상으로 사용하고 `#F5B942`를 강조점으로 사용한다. 앱 이름과 핵심 메시지는 `Inter` 계열로 조판한다. 이 값들은 사용자 제공 브랜드 입력이며, 임의의 색상·서체 토큰을 추가하지 않는다.

## Feature graphic 적용

feature graphic은 추상적인 궤도와 메모 모티프를 사용해 “생각을 놓치지 마세요”라는 메시지를 시각화한다. 배경은 파란 계열의 깊이감으로 구성하고, 황금색은 핵심 오브젝트·강조 텍스트에 제한한다. Google Play의 축소·크롭에서도 핵심 요소가 남도록 중앙에 초점을 둔다.

실제 앱 UI, 아이콘, 스크린샷이 제공되면 같은 색상과 타이포그래피를 유지하는지 추가 검수한다. 현재는 제품 UI 연속성을 확인할 근거가 없다.
