# 제품 UI 디자인 시스템

## 목적과 범위

이 문서는 조밀한 업무 정보에서도 핵심 행동이 먼저 보이는 차분한 도구라는 방향을 제품 UI 전반의 공통 규칙과 플랫폼별 적응 규칙으로 관리한다. 웹 브라우저 제품은 현재 범위에 포함하며, 모바일의 구체적인 플랫폼 범위는 아직 확정되지 않았다.

주요 독자는 제품·디자인·개발·품질 팀이다. 공통 원칙은 플랫폼 중립적으로 유지하고, 입력 방식과 표시 환경에 따른 차이만 플랫폼 문서에 둔다.

## 승인된 방향과 근거

- **방향 권위:** 제품 방향으로 승인된 사용자 요청
- **승인된 방향:** 조밀한 업무 정보에서도 핵심 행동이 먼저 보이는 차분한 도구를 지향한다. 정보량이 많아도 우선순위와 다음 행동이 즉시 식별되어야 하며, 표현은 업무 수행을 방해하지 않는 차분함을 유지한다.
- **대표 검증:** 단순 폼, 복잡한 표, 키보드 사용, 터치 사용에서 대표 검증 완료
- **성숙도:** 디자인 시스템 문서화

## 결정 분류

- **불변:** 핵심 행동이 먼저 보이는 정보 계층과 차분한 업무 도구의 방향
- **가변:** 콘텐츠 양과 작업 복잡도에 따른 정보 밀도와 배치
- **조건부:** 브라우저의 키보드 중심 입력과 웹 탐색 관례에 따른 적응. 모바일 적응은 대상 플랫폼 확정 후 정의한다.
- **금지:** 정보 밀도나 장식이 핵심 행동의 식별을 가리는 표현
- **검증:** 단순 폼과 복잡한 표에서 핵심 행동의 식별 가능성을 확인하고, 키보드와 터치 사용에서 대표 작업을 완료할 수 있는지 확인한다.

플랫폼 파일은 공통 방향을 복제하지 않고 해당 플랫폼의 차이만 정의한다. 문서 간 충돌이 있으면 이 인덱스의 범위와 결정 분류를 우선하고, 각 영역의 정본 소유자가 세부 결정을 관리한다.

## 미해결 결정

‘모바일’이 iOS와 Android를 모두 뜻하는지, 아니면 우리 앱의 내부 분류 이름인지 아직 확정되지 않았다. 이 결정이 내려지면 해당 플랫폼을 정본 이름으로 확정하고 필요한 적응 문서를 추가한다.
