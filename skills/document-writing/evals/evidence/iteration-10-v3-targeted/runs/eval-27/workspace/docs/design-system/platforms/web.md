# 웹 브라우저 플랫폼

## 범위

이 문서는 웹 브라우저 제품에만 적용되는 차이를 관리한다. 공통 방향은 [공통 기반](../foundations.md)을 따른다.

## 플랫폼 적응

- **입력:** 키보드 사용을 대표 입력 방식으로 고려하며, 대표 작업에서 핵심 행동과 현재 위치를 식별하고 완료할 수 있어야 한다.
- **환경:** 브라우저 제품의 탐색과 표시 환경에 맞춰 정보가 조밀한 화면에서도 핵심 행동의 우선순위를 유지한다.
- **검증:** 단순 폼과 복잡한 표를 웹 브라우저에서 확인하고, 키보드 사용으로 대표 작업을 완료할 수 있는지 확인한다. 터치 사용 검증은 공통 입력 검증의 근거이며 웹 전용 규칙으로 확장하지 않는다.

## 공통 규칙과의 관계

웹 플랫폼 적응은 핵심 행동 우선과 차분한 표현을 바꾸지 않는다. 브라우저 관례나 키보드 입력을 이유로 부가 정보가 핵심 행동보다 앞서도록 만들지 않는다.

모바일(iOS·Android 또는 제품 내부 분류)의 범위는 아직 결정되지 않았으므로 이 문서에서 모바일 규칙을 추정하지 않는다.
