# 접근성과 입력 검증

## 공통 계약

접근성은 승인된 방향을 보정하는 공통 조건이다. 정보가 조밀한 화면에서도 핵심 행동과 현재 상태를 식별할 수 있어야 하며, 입력 방식에 관계없이 대표 작업을 완료할 수 있어야 한다.

## 검증 범위

- 단순 폼에서 주요 입력과 제출 행동을 식별하고 완료할 수 있는지 확인한다.
- 복잡한 표에서 핵심 정보와 관련 행동의 우선순위를 파악할 수 있는지 확인한다.
- 키보드 사용과 터치 사용 각각에서 대표 작업을 완료할 수 있는지 확인한다.

구체적인 대비값, 크기, 포커스 표시, 플랫폼 접근성 API 매핑은 승인된 값이나 플랫폼 범위가 확인된 뒤 해당 정본에 추가한다. 확인되지 않은 요구사항은 추정하지 않는다.
