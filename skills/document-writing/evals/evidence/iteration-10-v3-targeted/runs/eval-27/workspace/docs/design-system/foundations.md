# 공통 기반

## 방향

조밀한 업무 정보에서도 핵심 행동이 먼저 보이는 차분한 도구를 만든다. 정보량이 증가해도 우선순위와 다음 행동의 식별 가능성을 유지하며, 시각적 표현은 업무 수행을 보조하는 수준으로 절제한다.

## 공통 원칙

- **정보 계층:** 핵심 행동과 작업에 필요한 정보가 부가 정보보다 먼저 읽혀야 한다.
- **밀도:** 단순한 작업과 복잡한 작업은 정보량과 배치를 달리할 수 있지만, 밀도가 핵심 행동을 숨겨서는 안 된다.
- **표현:** 장식적 표현보다 업무 맥락과 행동의 명료성을 우선한다.

## 결정 분류

- **불변:** 핵심 행동 우선, 조밀한 업무 정보에서도 유지되는 명료한 계층, 차분한 도구라는 상위 방향
- **가변:** 화면의 정보량과 작업 복잡도에 따른 밀도와 배치
- **조건부:** 입력 방식과 플랫폼 관례에 따른 상호작용 표현. 구체적인 차이는 [웹 플랫폼 적응](platforms/web.md)에서 관리한다.
- **금지:** 핵심 행동보다 장식 또는 부가 정보가 먼저 주목되는 구성
- **검증:** 단순 폼과 복잡한 표 모두에서 핵심 행동이 먼저 식별되는지 확인한다.

이 문서에 승인되거나 검증된 값이 없는 토큰, 크기, 색상, 서체, 모션 수치는 추가하지 않는다.
