# iOS

## 범위

iOS 앱의 조건부 적응을 소유한다. 공통 방향과 원칙은 [foundations.md](../foundations.md)를 따른다.

## 조건부 차이

- 짧은 완료 흐름에서는 화면 폭과 터치 입력에 맞춰 한 번에 이해할 정보와 다음 행동을 우선한다.
- 네이티브 내비게이션·상태·접근성 관례가 기능 명료성을 높이는 경우 우선할 수 있다. 구체 컴포넌트와 수치는 미결정이다.
- 의미 있는 전환은 친근함을 보탤 수 있으나 완료 결과를 지연하거나 가리지 않으며, 감소된 움직임에서는 축약·대체한다.

## 검증

짧은 대표 완료 흐름에서 현재 단계, 다음 행동, 완료 결과가 빠르게 이해되는지 확인한다.
