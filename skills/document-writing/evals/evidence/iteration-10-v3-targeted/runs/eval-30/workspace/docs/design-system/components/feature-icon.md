# Feature Icon

## Purpose

16px 기능 아이콘에서 기능을 빠르게 식별하게 하는 보조 시각 요소다.

## Anatomy and sizes

작은 크기에서 의미를 보존하는 단순한 실루엣과 정밀한 형태 언어를 사용한다. 16px은 대표 검증 조건이며, 세부 묘사보다 판독성을 우선한다.

## Adaptive rules

기능 아이콘은 큰 로고의 존재감을 복사하지 않는다. 크기와 기능에 따라 세부를 덜어낼 수 있지만 공통 무게와 절제 원칙은 유지한다.

## Accessibility

아이콘만으로 핵심 의미를 전달하지 않으며, 필요한 경우 텍스트 또는 접근성 이름을 함께 제공한다. 구체 접근성 이름 규칙은 [accessibility.md](../accessibility.md)를 따른다.

## Usage and prohibited usage

16px에서 과도한 선·장식·색상 차이로 의미를 분해하는 사용을 금지한다. 구체 선 두께·색상·토큰 값은 미결정이다.
