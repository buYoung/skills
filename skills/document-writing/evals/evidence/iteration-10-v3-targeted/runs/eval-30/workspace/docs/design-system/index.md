# 제품 UI 디자인 시스템

## 목적과 범위

웹 관리자 제품과 iOS 앱, 그리고 두 환경에서 사용하는 로고와 기능 아이콘을 하나의 제품 UI 언어로 운영한다. 이 문서는 재사용 가능한 시각·상호작용 결정을 소유하며, 구현물이나 이미지 산출물 자체는 포함하지 않는다.

## 승인된 방향

**차분하고 정밀하며 정보 위계가 먼저 보이되, 모서리와 움직임에서 약간의 친근함을 준다.** 정보 밀도와 기능 명료성은 공통으로 유지하고, 화면 크기·입력 방식·표현 맥락에 따라 형태와 밀도는 달리한다.

승인 근거는 사용자 요청에 명시된 방향과 대표 검증 결과다. 검증된 상황은 조밀한 웹 데이터 표, 짧은 iOS 모바일 완료 흐름, 큰 헤더 로고, 16px 기능 아이콘이다.

## 결정 분류

| 분류 | 정본 규칙 |
| --- | --- |
| 불변 | 정보 위계 우선, 정밀한 형태, 절제된 표현, 모서리·움직임의 제한적 친근함 |
| 가변 | 화면 밀도, 크기, 여백, 상태 표현, 로고와 아이콘의 시각적 무게 |
| 조건부 | 웹의 표·관리자 밀도, iOS의 짧은 완료 흐름·네이티브 관례, 큰 헤더와 16px 아이콘의 판독 조건 |
| 금지 | 장식이 정보보다 앞서는 구성, 맥락과 무관한 동일 크기·밀도 강제, 작은 아이콘에 세부 묘사 과다 |
| 검증 | 대표 상황에서 다음 행동과 정보 계층이 즉시 보이고, 공통 방향은 유지되며 맥락별 형태는 기능에 맞게 달라지는가 |

## 권위와 충돌 해결

이 문서의 승인 방향과 대표 검증 결과가 현재 제공된 권위 입력이다. 이후 브랜드·제품 결정이 추가되면 명시적으로 승인된 최신 결정이 우선하고, 공통 원칙과 플랫폼 파일이 충돌하면 공통 원칙은 유지하되 플랫폼 파일은 해당 플랫폼에서 필요한 차이만 소유한다. 구체 토큰 값, 플랫폼 정책, 수치 제약은 권위 자료가 제공될 때 확정한다.

## 미결정 사항

색상·타이포그래피·간격·모션의 구체 토큰 값과 접근성 수치 기준은 제공되지 않았다. 해당 값은 관례로 채우지 않고 제품·브랜드 권위 자료와 검증 결과로 확정한다.
