# Tokens

## 역할

토큰은 승인된 디자인 결정을 구현에 연결하는 정본이다. 현재 입력에는 구체 값·이름·테마가 제공되지 않았으므로 아래는 소유해야 할 계층과 미결정 상태만 정의한다.

## 토큰 계층

| 계층 | 소유 내용 | 상태 |
| --- | --- | --- |
| 원천 토큰 | 색, 글꼴, 크기, 간격, 모서리, 움직임의 원천 값 | 미결정 |
| 의미 별칭 | 정보·상태·강조·표면 등 의미와 원천 값의 매핑 | 미결정 |
| 컴포넌트 바인딩 | 로고·기능 아이콘·표·완료 흐름이 의미 별칭을 소비하는 방식 | 일부 방향만 승인 |

## 승인된 의미

토큰은 정보 위계를 우선하고, 정밀한 구조와 제한된 친근함을 지원해야 한다. 웹의 조밀함이나 iOS의 짧은 흐름을 위해 값이 달라질 경우 그 차이는 플랫폼·크기 조건에 귀속하며 공통 의미를 바꾸지 않는다.

## 확정이 필요한 값

색상 값, 글꼴·크기, 간격 체계, 모서리 값, 모션 지속 시간, 테마·모드, 토큰 명명 규칙은 권위 있는 브랜드·제품 자료와 대표 결과를 확인한 뒤 확정한다. 관례값을 임의로 추가하지 않는다.
