# Web

## 범위

브라우저 기반 관리자 제품의 조건부 적응을 소유한다. 공통 방향과 원칙은 [foundations.md](../foundations.md)를 따른다.

## 조건부 차이

- 많은 정보를 비교하는 데이터 표에서는 정렬·행 관계·상태 위계를 보존한 채 밀도를 높일 수 있다.
- 포인터·키보드 입력과 넓은 화면에 맞춰 표의 열, 호버·포커스·선택 상태를 표현한다. 구체 동작과 수치는 미결정이다.
- 큰 헤더 로고는 업무 화면의 위계를 침범하지 않는 범위에서 브랜드 존재감을 가질 수 있다.

## 검증

조밀한 대표 표에서 핵심 값, 상태, 다음 동작이 장식보다 먼저 보이는지 확인한다.
