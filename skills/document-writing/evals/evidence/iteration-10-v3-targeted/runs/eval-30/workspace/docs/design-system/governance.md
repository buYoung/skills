# Governance

## 현재 상태와 권위

현재 시스템은 승인된 방향과 네 가지 대표 상황으로 검증된 문서화 상태다. 승인 방향의 권위는 사용자 요청이며, 검증 근거는 조밀한 웹 데이터 표, 짧은 iOS 완료 흐름, 큰 헤더 로고, 16px 기능 아이콘이다.

## 변경 원칙

공통 원칙을 바꾸는 변경은 방향 승인과 대표 상황 재검증이 필요하다. 플랫폼 차이만 바꾸는 경우에는 해당 플랫폼 파일과 영향을 받는 대표 상황을 검토한다. 변경은 항상 결정의 소유 파일에 기록하고 `index.md`의 지도와 충돌 해결 규칙을 갱신한다.

## 검토 기준

검토자는 공통 위계·정밀성·절제·친근함이 유지되는지, 맥락별 밀도·형태·움직임 차이가 기능적 이유를 갖는지, 작은 크기에서도 판독성과 접근성이 유지되는지 확인한다. 구체적인 담당자, 릴리스 주기, 수명주기 상태는 제공되지 않아 미결정이다.
