# Patterns

## 조밀한 데이터 표

관리자 업무에서 많은 정보를 빠르게 비교하는 패턴이다. 열·행·상태·주요 동작의 위계를 먼저 드러내며, 웹에서는 밀도를 높일 수 있지만 정렬과 그룹 관계는 유지한다. 작은 화면에서는 표를 동일하게 축소하지 말고 우선순위에 따라 재구성한다.

검증: 대표 데이터가 많아도 현재 위치, 핵심 값, 가능한 다음 동작을 구분할 수 있어야 한다.

## 짧은 모바일 완료 흐름

iOS에서 사용자가 적은 단계로 완료에 도달하는 패턴이다. 현재 단계와 완료 확인, 다음 행동을 우선하고 화면 폭과 입력 방식에 맞춘다. 완료 피드백은 친근할 수 있지만 기능 결과를 가리지 않는다.

검증: 흐름을 빠르게 훑을 때 사용자가 현재 상태와 완료 여부를 오해하지 않아야 한다.

## 공통과 맥락별 차이

공통은 위계, 정밀성, 절제, 제한된 친근함이다. 표는 비교를 위해 조밀해지고 완료 흐름은 단계 집중을 위해 단순해진다. 큰 헤더 로고는 브랜드 표현을 확장할 수 있지만 16px 기능 아이콘은 의미 판독을 위해 단순화한다. 이 차이를 불일치로 수정하지 않는다.
