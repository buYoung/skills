# Logo

## Purpose

제품과 브랜드를 식별하는 시각 요소로, 큰 헤더에서는 존재감을 제공하되 정보 위계를 압도하지 않는다.

## Adaptive rules

큰 헤더에서는 브랜드 표현을 확장할 수 있다. 작은 UI 맥락에서는 식별성과 공간 제약을 우선해 단순화할 수 있다. 형태를 모든 크기에 동일하게 강제하지 말고 [foundations.md](../foundations.md)의 정밀성·절제 원칙을 유지한다.

## Usage and prohibited usage

정보보다 장식적 존재감이 앞서는 배치, 맥락과 무관한 동일 크기 강제, 승인되지 않은 변형은 금지한다. 구체 비율·여백·색상·파일 규격은 미결정이다.
