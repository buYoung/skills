# Content

## 정보 위계

레이블과 제목은 사용자가 무엇을 보고 있는지 즉시 알려야 하며, 핵심 값과 상태는 보조 설명보다 먼저 발견되어야 한다. 행동 문구는 다음 행동을 모호하게 만들지 않는다.

## 맥락별 작성

웹 관리자 표는 짧고 반복 가능한 열·상태 표현을 우선한다. iOS 완료 흐름은 한 화면에서 이해할 수 있는 짧은 문장과 명확한 완료 표현을 우선한다. 두 맥락 모두 친근한 표현이 상태나 행동의 정확성을 약화시키면 사용하지 않는다.

## 미결정

제품 용어집, 오류·검증 문구, 날짜·숫자·지역화 형식은 제공되지 않았다. 확정 전에는 임의의 제품 용어 또는 문구 규칙을 정본으로 만들지 않는다.
