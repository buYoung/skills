# Accessibility

## 공통 계약

정보 위계는 색상·크기·모션 하나에만 의존하지 않는다. 상태와 행동은 텍스트, 구조, 의미 있는 형태 또는 접근성 의미로도 전달해야 한다. 키보드·대체 입력, 의미 구조, 포커스, 확대·텍스트 크기, 대비, 감소된 움직임에 대한 구체 기준은 권위 자료 확인 후 확정한다.

## 방향과의 관계

정밀한 표 구조는 탐색 순서와 의미 구조를 명확히 해야 하며, 단순한 16px 아이콘은 보조 라벨·접근성 이름과 함께 의미를 전달해야 한다. 친근한 움직임은 감소된 움직임 설정에서 결과와 상태를 잃지 않고 축약·대체된다.

## 검증

대표 웹 표와 iOS 완료 흐름에서 정보, 현재 상태, 다음 행동, 완료 결과를 시각적 효과가 줄어든 조건과 보조 입력으로도 파악할 수 있는지 확인한다. 수치 합격 기준은 미결정이다.
