# 자산 시스템

## 역할과 관계

| 자산 | 역할 | 다른 자산과의 관계 |
| --- | --- | --- |
| 앱 아이콘 | 작은 크기에서 제품을 식별 | 스크린샷·feature graphic의 식별 단서와 연결하되 복제하지 않는다 |
| 스크린샷 | 실제 기능·화면·경험의 증거 | 화면 선택과 순서는 [screenshots-and-previews.md](screenshots-and-previews.md)가 소유 |
| preview video | 움직임과 핵심 흐름을 짧게 보여주는 증거 | 첫 장면과 cover 관계는 Google Play 규격에 따르고, 실제 경험을 우선 |
| feature graphic | 목록·영상 cover 등에서 경험을 보조하는 넓은 시각 앵커 | 아이콘과 같은 계열로 인식되되 동일한 표식을 반복하지 않는다 |

## 공통 소스와 관계 규칙

모든 자산은 동일한 승인 방향, 최신 제품 빌드, 승인된 카피·현지화 소스를 사용한다. 자산별 규격·필수 여부·업로드 관계는 [stores/google-play.md](stores/google-play.md)만 소유한다. 공통 파일에는 스토어의 크기·개수·형식·정책을 복제하지 않는다.

## 검증 기준

아이콘만 보아도 제품 식별이 가능하고, 스크린샷은 실제 기능을 증명하며, 영상은 상호작용의 흐름을 보여주고, feature graphic은 제품 화면과 경쟁하지 않아야 한다. 네 자산을 나란히 놓았을 때 강조색의 의미와 제품 화면의 시각 언어가 이어져야 한다.
