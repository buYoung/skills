# 접근성

- 색만으로 기능·상태를 전달하지 말고 형태, 위치, 텍스트 또는 실제 UI 단서를 함께 제공한다.
- 작은 아이콘·축소된 스크린샷·영상 썸네일에서 충분한 대비와 식별성을 확인한다.
- 이미지 자산마다 핵심 맥락을 설명하는 140자 이내의 대체 텍스트를 제공한다.
- preview video는 자막을 제공하고, 무음 재생에서도 핵심 흐름이 이해되도록 구성한다.
- 장식이 텍스트·UI·핵심 초점을 가리지 않도록 한다.

접근성 요구가 시각 방향과 충돌하면 실제 정보 전달과 읽기 가능성을 우선한다. 검토 결과는 [delivery-and-versioning.md](delivery-and-versioning.md)의 검증 기록에 남긴다.
