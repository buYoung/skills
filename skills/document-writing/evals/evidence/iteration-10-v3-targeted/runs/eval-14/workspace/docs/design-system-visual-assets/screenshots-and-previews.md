# 스크린샷과 preview

## 스크린샷

첫 화면부터 실제 제품의 핵심 기능을 보여준다. 정보가 많은 화면은 한 장에 모든 기능을 넣기보다 핵심 계층을 먼저 보이게 하고, 화면 밖의 손가락·기기 사진·불필요한 장식을 넣지 않는다. 추가 카피는 핵심을 설명할 때만 사용하며, 카피가 UI를 가리지 않도록 한다.

순서는 사용자가 제품 가치를 이해하는 흐름으로 정한다: 핵심 결과 → 주요 기능 → 신뢰를 주는 세부 흐름. 지원 장치가 다르면 해당 장치의 실제 화면을 별도 변형으로 제공한다.

## preview video

첫 10초 안에 실제 앱의 핵심 경험을 보여주고, 영상 대부분은 실제 사용 경험으로 구성한다. 타이틀·로고·홍보 장면은 보조로 제한한다. 무음 자동재생을 고려해 읽을 수 있는 짧은 화면 카피와 자막을 제공한다. 영상은 스크린샷을 반복하는 대신 시간적 흐름과 전환을 보여준다.

## 관계 검증

preview cover가 feature graphic과 연결되더라도 영상이 제공하지 않는 기능을 암시하지 않는다. 스크린샷 첫 장과 영상 첫 장은 같은 핵심 메시지를 공유하되 동일한 프레임을 기계적으로 복제하지 않는다.
