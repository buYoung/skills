# 시각 언어

## 승인된 방향

실제 제품 화면을 주인공으로 삼고 장식을 절제한다. 단 하나의 선명한 강조색을 의미 있는 전환·핵심 기능·행동에 집중해 진취적인 인상을 만든다.

## 결정 분류

- **불변:** 제품 UI·게임플레이는 자산의 가장 강한 증거이며, 장식보다 우선한다. 자산 전체에서 강조색은 한 가지 역할로 인식되어야 한다.
- **가변:** 화면 수, 정보량, 크기, 세로·가로 구성은 제품 기능과 노출 맥락에 맞춰 바꾼다. 아이콘은 단순화하고, 정보가 많은 스크린샷은 계층과 여백을 늘린다.
- **조건부:** Google Play가 요구하는 장치 유형·배치·형식은 `stores/google-play.md` 규칙에 맞춘다. 동영상은 무음 자동재생을 고려해 시각적으로도 이해되어야 한다.
- **금지:** 제품에 없는 기능을 보여주는 합성, 순위·가격·성과를 암시하는 표현, 과도한 로고·장식, 여러 강조색의 경쟁, 스토어 배지·기기 사진의 장식적 사용.
- **검증:** 1) 실제 UI가 첫 시선에 식별되는가, 2) 강조색이 한 의미 체계로 작동하는가, 3) 축소·무음·고밀도 상황에서 핵심이 읽히는가, 4) 자산 간 제품·브랜드 연속성이 유지되는가.

## 연속성

앱 아이콘은 제품의 식별 단서만 남긴 가장 작은 표현이다. 스크린샷과 영상은 실제 제품을 증거로 확장하며, feature graphic은 같은 인상을 넓은 캔버스에서 보조한다. 어느 자산도 제품 화면을 대체하는 광고 일러스트가 되지 않는다.
