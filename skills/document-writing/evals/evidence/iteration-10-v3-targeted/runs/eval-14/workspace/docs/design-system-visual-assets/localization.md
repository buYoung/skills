# 현지화

## 원칙

번역된 카피, 브랜딩 문구, 영상 UI·자막·음성을 지원 시장별로 검토한다. 텍스트가 들어간 스크린샷과 영상은 언어별 변형을 관리하고, 번역 확장으로 UI나 안전 영역이 침범되지 않는지 확인한다.

## 조건부 적용

오른쪽에서 왼쪽으로 읽는 언어는 레이아웃 방향과 시선 흐름을 검토하되 실제 제품 UI의 방향 규칙을 우선한다. 문화적으로 오해될 수 있는 이미지·제스처·색 의미는 지역 검토를 거친다. 번역이 준비되지 않은 경우 승인된 기본 언어 자산을 임의로 번역해 배포하지 않고 상태를 미해결로 기록한다.

## 검증

각 변형에서 카피가 잘리지 않고, 핵심 UI가 실제 제품과 일치하며, 강조색의 의미가 바뀌지 않는지 확인한다. 대체 텍스트도 해당 언어로 제공한다.
