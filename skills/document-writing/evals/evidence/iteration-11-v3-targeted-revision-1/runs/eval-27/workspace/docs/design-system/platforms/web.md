# 웹 플랫폼 적응

웹은 브라우저 제품을 뜻한다. 이 파일은 공통 방향을 유지하면서 브라우저의 입력·탐색 맥락에 필요한 차이만 관리한다.

## 조건부 규칙

- 키보드 사용은 핵심 행동과 조밀한 정보 구조를 탐색하는 대표 입력 맥락으로 검증한다.
- 복잡한 표에서는 정보량이 많아도 핵심 행동과 표의 구조가 먼저 식별되도록 공통 패턴을 적용한다.
- 단순 폼에서는 브라우저 입력 흐름이 핵심 행동으로 자연스럽게 이어지는지 확인한다.
- 플랫폼 차이를 이유로 차분한 도구의 방향이나 핵심 행동 우선순위를 공통 규칙에서 제거하지 않는다.

## 검증

단순 폼과 복잡한 표를 키보드 사용 맥락에서 확인한다. 핵심 행동의 발견 가능성과 업무 흐름이 유지되지 않으면 공통 규칙과 웹 적응 중 어느 소유 수준의 문제인지 기록하고 해당 정본을 수정한다.

웹의 구체적인 브라우저 API, 치수, 토큰, 네이티브 컴포넌트 규칙은 승인되거나 검증된 근거가 없어 추가하지 않는다.
