# 제품 UI 디자인 시스템

## 목적과 범위

이 문서는 조밀한 업무 정보를 다루는 제품 UI에서 재사용할 시각·상호작용 원칙을 관리한다. 웹 브라우저 제품은 별도 플랫폼 파일에서 관리하며, 모바일의 구체적 범위는 아직 확정되지 않았다.

## 승인된 방향

승인된 방향은 **조밀한 업무 정보에서도 핵심 행동이 먼저 보이는 차분한 도구**다. 정보량이 많은 화면에서도 우선순위와 다음 행동을 분명히 하되, 업무를 방해하는 장식적 표현은 억제한다.

- 방향 상태: 승인 및 대표 검증 완료
- 방향 권위: 사용자 요청의 승인된 제품 UI 방향
- 검증 상황: 단순 폼, 복잡한 표, 키보드 사용, 터치 사용

## 결정 분류

- 불변: 핵심 행동이 정보 밀도보다 먼저 인지되어야 하며, 차분한 도구라는 방향을 유지한다.
- 가변: 정보 구조와 밀도는 화면의 업무 복잡도와 내용에 따라 달라질 수 있다.
- 조건부: 웹 브라우저의 입력·탐색 차이는 `platforms/web.md`에서 관리한다. 모바일 차이는 구체 플랫폼 범위가 정해진 뒤 별도 파일로 관리한다.
- 금지: 핵심 행동을 가리는 장식적 표현, 플랫폼 차이를 공통 규칙으로 일반화하는 것.
- 검증: 단순 폼과 복잡한 표에서 핵심 행동의 우선순위가 즉시 드러나는지, 키보드와 터치 사용에서 업무 흐름이 유지되는지 확인한다.

## 우선순위

이 문서 세트의 구체 규칙은 해당 영역의 정본을 따르며, 플랫폼 파일은 공통 규칙을 재정의하지 않고 조건부 차이만 정의한다. 충돌 시 승인된 방향과 대표 검증 기준을 먼저 적용하고, 해결되지 않은 충돌은 임의로 선택하지 않는다.
