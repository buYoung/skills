# 공통 파운데이션

## 상위 원칙

- 조밀한 업무 정보에서도 핵심 행동과 우선순위가 먼저 보인다.
- 차분한 도구의 인상을 유지하고, 장식은 업무 이해와 행동을 방해하지 않는 범위로 제한한다.
- 플랫폼별 입력과 탐색 차이는 공통 원칙을 유지하면서 조건부로 적응한다.

## 결정 분류

- 불변: 정보 위계는 핵심 행동을 우선 노출한다.
- 가변: 화면의 정보 밀도와 배치는 업무 복잡도에 맞춘다.
- 조건부: 웹 브라우저의 키보드·탐색 차이는 [웹 플랫폼 규칙](platforms/web.md)을 따른다.
- 금지: 정보가 조밀하다는 이유로 핵심 행동을 보조 정보 아래에 숨기는 구성.
- 검증: 단순 폼과 복잡한 표 모두에서 핵심 행동과 다음 단계가 먼저 식별되는지 확인한다.

## 값이 아직 정해지지 않은 영역

색상 값, 타이포그래피 값, 간격 토큰, 컴포넌트 치수, 모션 값은 이 입력에서 승인되거나 검증되지 않았다. 근거 없이 수치나 토큰을 추가하지 않는다.
