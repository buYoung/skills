# Troubleshooting runbook structure

## Default structure

1. Title and affected system
2. Symptoms and triggering signals
3. Impact and severity
4. Safety checks and prerequisites
5. Quick triage
6. Diagnostic decision branches
7. Recovery actions
8. Verification
9. Rollback
10. Escalation criteria and required evidence
11. Follow-up or prevention references

## Branch contract

Each diagnostic branch should state:

- Observable condition
- Check to perform
- Expected evidence
- Next branch or recovery action
- Stop or escalation condition

## Recovery contract

Each material recovery action should state risk, expected change, verification, and rollback where practical.
