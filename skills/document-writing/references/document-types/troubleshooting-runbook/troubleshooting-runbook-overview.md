# Troubleshooting runbook

## Purpose

Help an operator diagnose and recover from an abnormal state safely, using observable conditions, bounded actions, verification, rollback, and escalation.

## Select this type when

- The reader starts with a symptom, alert, failure, or degraded state.
- Diagnosis branches based on evidence.
- Recovery safety, verification, rollback, and escalation matter.

## Route elsewhere when

- The reader follows a normal setup or usage path: action guide.
- The artifact only records a past incident: record.
- The artifact analyzes an incident after the fact: analysis report.
- It defines product-level failure behavior rather than operational recovery: FDD.
