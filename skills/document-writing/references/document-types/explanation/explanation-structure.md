# Explanatory overview structure

Use only the sections that help the intended reader.

## Default structure

1. Title
2. One-sentence conclusion or definition
3. Why this matters
4. Core explanation organized by concept
5. Concrete example or scenario
6. Limits, exceptions, or related material

## Section responsibilities

### Opening

Answer what the document is about and give the reader the most important takeaway. Do not begin with a long history unless the history is necessary to understand the conclusion.

### Core explanation

Move from familiar ideas to unfamiliar ones. Give each heading one conceptual responsibility. Define terms before depending on them.

### Examples

Use a realistic case, input and output, or before-and-after comparison. Explain why the example behaves as shown.

### Limits and references

Keep caveats near the claim they modify. Use a closing section only for secondary limitations or further reading.

## Optional forms

- Comparison table for repeated dimensions
- FAQ for genuinely recurring reader questions
- Glossary when several domain terms recur
- Diagram description when relationships are difficult to explain linearly
