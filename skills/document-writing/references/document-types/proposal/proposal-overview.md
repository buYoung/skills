# Proposal

## Purpose

Help a decision-maker choose, approve, fund, or commit to a future action.

## Select this type when

- The document contains a concrete decision request.
- Alternatives and tradeoffs must be compared.
- A recommendation needs evidence, impact, cost, and risk.

## Route elsewhere when

- The document only communicates findings: analysis report.
- It defines how an already selected product feature should behave: FDD.
- It establishes durable mandatory rules: policy or rules.
- It preserves a past decision without seeking a new one: record.

A request to review an existing document is an operation, not evidence that the target type is proposal.
