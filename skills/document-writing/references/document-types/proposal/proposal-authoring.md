# Authoring a proposal

## Required context

Identify the decision-maker, decision deadline, problem, desired outcome, constraints, credible options, evidence, and consequences of delay or inaction.

## Drafting sequence

1. Write the recommendation and decision request.
2. Define the problem without presupposing the solution.
3. Establish decision criteria.
4. Develop credible options, including the status quo when relevant.
5. Compare options using consistent criteria.
6. Explain the recommendation from evidence and tradeoffs.
7. State costs, risks, dependencies, and reversibility.
8. End with one compact approval or commitment statement. Repeat only the terms the decision-maker must approve, not the evidence or rationale already established above.

## Evidence discipline

Distinguish known facts, estimates, assumptions, and judgments at the point where each claim supports the decision. Give each material claim one canonical home and refer back to it rather than restating it. Use a separate evidence inventory only when the number or provenance of sources makes point-of-use labels insufficient.

Use ranges or scenarios when point estimates imply false precision. Keep limitations and safety conditions that change the recommendation, approval terms, or reader action; state each at its decision point and repeat it only when the closing commitment would otherwise be unsafe or ambiguous.

## Avoid

- Hiding the ask until the conclusion
- Treating preference as evidence
- Comparing options on different dimensions
- Describing a product feature design when the actual decision has already been made
