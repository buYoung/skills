# Action guide structure

## Default structure

1. Title
2. Outcome statement
3. Prerequisites
4. Ordered steps
5. Completion verification
6. Troubleshooting for common, local failures
7. Related reference material

## Step contract

Each meaningful step should contain:

- Action: exactly what the reader does
- Location or input: where and with what value
- Expected result: what observable state confirms success
- Conditional note: only when the step has a real branch or hazard

Do not force this formatting on trivial steps.

## Troubleshooting boundary

Include a short troubleshooting section for predictable failures in this task. If diagnosis is the document's primary value or requires branching triage and recovery, route to a runbook instead.
