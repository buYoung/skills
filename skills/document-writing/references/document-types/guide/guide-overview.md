# Action guide

## Purpose

Enable a reader to complete a known task from a normal starting state by following an ordered, verifiable path.

## Select this type when

- The reader has a concrete outcome to achieve.
- The expected path is mostly linear.
- Prerequisites, actions, expected results, and completion checks matter.

## Route elsewhere when

- The reader starts from a failure and must diagnose branches: troubleshooting runbook.
- The reader mainly looks up options or exact syntax: reference or specification.
- The document explains concepts without asking the reader to act: explanatory overview.
