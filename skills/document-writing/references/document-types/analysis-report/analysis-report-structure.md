# Analysis report structure

## Default structure

1. Title
2. Executive summary
3. Question, scope, and time period
4. Sources and method
5. Findings
6. Interpretation and implications
7. Recommendations, when requested
8. Limitations and uncertainty
9. Appendix or underlying detail

## Responsibility boundaries

### Findings

State what the evidence shows. Organize by the analytical question, not by source order.

### Interpretation

Explain why the findings matter and what causal or contextual meaning is reasonably supported. Label inference.

### Recommendations

Tie each recommendation to a finding and state important tradeoffs. Omit this section when the user asked only for analysis.

### Limitations

Describe gaps that could change interpretation, not generic disclaimers.
