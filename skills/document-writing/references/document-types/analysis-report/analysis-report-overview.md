# Analysis report

## Purpose

Communicate evidence, findings, interpretation, implications, and limitations so readers can understand a situation or result.

## Select this type when

- The central value is what the evidence shows.
- Scope, method, findings, and limitations affect credibility.
- Recommendations may follow, but an immediate approval request is not the document's defining purpose.

## Route elsewhere when

- The primary purpose is to obtain a decision: proposal.
- The primary value is a neutral chronology: record or meeting notes.
- The content explains a concept without an evidence question: explanatory overview.
- The document defines one feature's design source: FDD.
