# Authoring an analysis report

## Required context

Identify the analytical question, audience, decision context, time boundary, data sources, method, comparison baseline, and known limitations.

## Drafting sequence

1. Write the answer to the analytical question in a short executive summary.
2. Define scope, period, source coverage, and method.
3. Group evidence into a small set of findings.
4. Distinguish observed fact from interpretation.
5. Explain material implications.
6. Add recommendations only when supported and requested.
7. State uncertainty and missing evidence that could change the result.
8. Move supporting detail to an appendix when it interrupts the main argument.

## Evidence discipline

- Use consistent denominators, time periods, and comparison baselines.
- Explain material data transformations.
- Avoid implying causation from correlation.
- Label estimates and assumptions.
- Prefer exact sourced values over adjectives such as "large" or "significant".

## Avoid

- A chronological dump of research notes
- Repeating the executive summary in every section
- Recommendations unrelated to findings
- Decorative methodology that does not affect credibility
