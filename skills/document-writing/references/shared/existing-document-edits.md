# Existing document edits

Use this reference whenever the user supplies an existing document for update, rewrite, review, fact-check, or normalization.

## Preserve before changing

- Read the complete target and any template or governing reference first.
- Identify the document type from explicit metadata, structure, lifecycle, and intended reader outcome.
- Preserve fenced code blocks, exact logs, paths, identifiers, quotations, links, and user-owned custom sections.
- Preserve the existing artifact path unless the user asks to move it or the type contract requires another canonical path.

## Operation boundaries

- Review: inspect and report findings; do not rewrite unless requested.
- Fact-check: verify material claims and cite evidence; do not silently correct.
- Update: change current facts while preserving relevant history.
- Rewrite: improve the requested content while retaining authoritative meaning and constraints.
- Normalize: move content into the right structural responsibilities and report what moved.

## Collision handling

Inspect the target before writing. Do not overwrite a different artifact, fork arbitrary version files, or create date-suffixed copies to avoid deciding which document is canonical. Ask when canonical ownership cannot be inferred safely.

## Final check

Compare the result against the original for accidental loss, changed meaning, broken links, and altered exact text. Report material movements or preserved limitations.
