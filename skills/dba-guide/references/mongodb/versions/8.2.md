# MongoDB 8.2 (end of life)

Checked: 2026-11-27 against the lifecycle page and the "Compatibility Changes Introduced in MongoDB 8.2" section of https://www.mongodb.com/docs/v8.3/release-notes/8.3-compatibility/. The 8.2 manual is now legacy documentation.

Read this only when a deployment still runs 8.2.x and must be moved to a supported series.

## Lifecycle

- First minor release offered to self-managed deployments. GA was September 2025 (lifecycle page). End of life was 2026-07-31 for both self-managed and Atlas Auto Upgrade.
- After end of life it receives no fixes, including security fixes.

## Changed Defaults

These carry forward into 8.3 and 9.0. See the 8.2 table in [8.3](8.3.md#changed-defaults): `orphanCleanupDelaySecs` 3600, GeoJSON priority in geospatial index generation, `$$CLUSTER_TIME` error on standalone, initial-sync index build memory at 10% of RAM.

## Removed or Deprecated

- `catalogCacheIndexMaxEntries` was removed.
- In 8.2.0 only, change events carried `collectionUUID` and `updateDescription.disambiguatedPaths` without `showExpandedEvents`. From 8.2.1 they appear only with `showExpandedEvents: true`. Do not rely on `commitTimestamp` in change events.

## Upgrading Into This Series

Not recommended: the series has ended. To leave 8.2:

- Forward: upgrade to the latest 8.3 (8.2 → 8.3 is a documented path), then optionally to 9.0. You cannot skip 8.3, because before 9.0 minor releases cannot be skipped.
- Back to a major: downgrade to 8.0 (the immediately preceding release), then upgrade 8.0 → 9.0. First remove 8.2-only persisted features, such as `errorAndLog` validation actions and views or validators that use newer expressions.
- Queryable Encryption collections that use the 8.2 public-preview prefix/suffix/substring query types must stay on 8.2/8.3, or be re-created for the 9.0 GA types (see [9.0](9.0.md#upgrading-into-this-series)).

Known issues listed for 8.2:
- SERVER-118428 in 8.2.4 and 8.2.5: `mongocryptd` messages capped at 16 KiB; unresolved.
- SERVER-110250 in 8.2.0: crashes when more than 1000 queries spill at once.
- SERVER-109626 in 8.2.0: up to 15% change stream regression; fixed in 8.2.1.
