# Redis 8.2

Checked: 2026-11-27. Read when the server reports `redis_version:8.2.x`, or when choosing a long-lived Redis 8 line (8.2 is the Extended release of Redis 8, supported to 2030-09-01).

## Lifecycle

- Extended release. GA 8.2.0 on 2025-08-04. End of support 2030-09-01.
- Official image `redis:8.2` reported 8.2.11 on 2026-11-27.
- License: RSALv2, SSPLv1, or AGPLv3.

## Changed Defaults

No default change of operating significance confirmed in the 8.2 release notes.

## Worth Adopting

- `CLUSTER SLOT-STATS`: per-slot key count, CPU time, network in/out. Use it to find hot slots before resharding. Only `key-count` is reported by default; CPU and network figures need `cluster-slot-stats-enabled yes` (present from 8.2.0, `redis.conf` of the 8.2.0 tag). On 8.2 and 8.4 it takes only `yes` or `no`; 8.6 changed it to a list (see [8.6](8.6.md)).
- Streams: `XDELEX` and `XACKDEL`, plus `KEEPREF`, `DELREF`, `ACKED` options on `XADD` and `XTRIM`, control what happens to consumer group references when entries are removed.
- `BITOP` operators `DIFF`, `DIFF1`, `ANDOR`, `ONE`.
- Keyspace notification events `OVERWRITTEN` and `TYPE_CHANGED`.
- Metrics: `used_memory_peak_time`; replica-side `master_current_sync_attempts`, `master_total_sync_attempts`, `master_link_up_since_seconds`, `total_disconnect_time_sec`; `CLIENT LIST` `tot-net-in`, `tot-net-out`, `tot-cmds`; `sentinel_total_tilt`.
- Security fixes in 8.2.0 also shipped to supported lines: CVE-2025-27151 (`redis-check-aof`), CVE-2025-32023 (HyperLogLog), CVE-2025-48367 (accept errors).

## Upgrading Into This Series

From 8.0: no breaking change confirmed in the 8.2 notes. Upgrade before 8.0 support ends on 2026-12-01. `SET ... IFEQ` and other 8.4 string commands are not available here (8.2.11 rejects `SET k v IFEQ x` with `ERR syntax error`), so applications written against 8.4+ docs fail on 8.2.

## Managed Service Notes

Not offered by ElastiCache or MemoryDB. See [managed services](../managed-services.md).
