# Redis 6.2

Checked: 2026-11-27. Read when the server reports `redis_version:6.2.x`, or when planning the move off 6.2 before its 2027-04-01 end of support.

## Lifecycle

- Extended release. GA 6.2.0 on 2021-02-22. End of support 2027-04-01 (version management page).
- Newest patch: 6.2.24 (2026-08-17), a security release. Patches since 6.2.16 are almost all security fixes (Lua, `RESTORE`, HyperLogLog, TLS). Run the newest 6.2 patch until the upgrade lands.
- License: BSD-3-Clause.
- Official image `redis:6.2` reported 6.2.24 on 2026-11-27 (`redis-server --version`: `Redis server v=6.2.24 sha=00000000:0 malloc=jemalloc-5.1.0 bits=64 ...`).

Defaults on the 6.2.24 image that differ from the 7.2 and later images: `repl-diskless-sync no`, `acl-pubsub-default allchannels`, no `enable-debug-command`, `busy-reply-threshold`, or `*-listpack-*` parameters (only the `*-ziplist-*` names), allocator `jemalloc-5.1.0`. Small hashes and sorted sets report encoding `ziplist`, a small set of non-integers `hashtable`, a small list `quicklist`. `SAVE` writes an RDB starting with `REDIS0009`. `MODULE LIST` is empty.

## Worth Adopting

Features that exist from 6.2 and that later files assume (each command below ran on the 6.2.24 image):

- `GETDEL`, `GETEX`, `SET ... GET`, `SET ... EXAT|PXAT`, `COPY`, `LMOVE`, `ZRANGE` with `BYSCORE`/`BYLEX`/`REV`, `HRANDFIELD`, `ZRANDMEMBER`.
- `FAILOVER` command: coordinated primary-to-replica switch without Sentinel.
- ACL Pub/Sub channel permissions (`&pattern`, `allchannels`, `resetchannels`). In 6.2 new users get `allchannels` by default (`acl-pubsub-default`; `ACL GETUSER` of a new user shows `allchannels` on 6.2.24); 7.0 flipped this.
- `CLIENT PAUSE ... WRITE` for a write freeze during maintenance.
- Sentinel hostname support (`resolve-hostnames`, `announce-hostnames`), off by default.

## Removed or Deprecated

Nothing in 6.2 itself that changes an operating decision. The removals that bite on upgrade arrive in 7.0; see [7.2](7.2.md).

## Upgrading Into This Series

Not applicable: 6.2 is the oldest covered series. For servers older than 6.2, see [Outside the Covered Range](index.md#outside-the-covered-range).

## Managed Service Notes

- ElastiCache: "ElastiCache version 6.2 for Redis OSS" exists; Redis OSS v6 standard support ends 2027-01-31, Extended Support (paid, in yearly premium tiers) runs to 2030-01-31.
- MemoryDB: "MemoryDB with Redis OSS version 6.2" exists; MemoryDB manages patch versions and does not let you choose one.
