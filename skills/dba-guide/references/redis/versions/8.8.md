# Redis 8.8

Checked: 2026-11-27. Read when the server reports `redis_version:8.8.x` (support ends 2027-01-29), or when adopting arrays, `INCREX`, or field-level hash notifications.

## Lifecycle

- Standard release. GA 8.8.0 on 2026-05-25. End of support 2027-01-29.
- Official image `redis:8.8` reported 8.8.4 on 2026-11-27.
- License: RSALv2, SSPLv1, or AGPLv3.

## Changed Defaults

- New `slowlog-entry-max-argc` (default 32) and `slowlog-entry-max-string-len` (default 128): slow log entries keep at most 32 arguments and 128 bytes per argument. The `SLOWLOG GET` page calls the first one `slowlog-max-argc`; the server parameter name on the 8.12 image is `slowlog-entry-max-argc`.
- Search default worker thread maximum changed; `MAX_WORKER_THREADS` is a string config.

## Removed or Deprecated

- A GCRA rate limiter present in 8.8 milestones was removed before GA in favor of `INCREX`.

## Worth Adopting

- Array data type (`@array` ACL category): ordered, indexable collection.
- `INCREX`: atomic window counter combining increment, bounds, and expiration; replaces `MULTI`/Lua rate-limit patterns.
- Hash field-level keyspace notifications.
- `XNACK`: a consumer releases pending stream entries explicitly.
- `COUNT` aggregator for `ZUNION`, `ZINTER`, `ZUNIONSTORE`, `ZINTERSTORE`.
- Batched prefetch for `MGET`, `MSET`, and `HGETALL` on hashtable hashes.

## Upgrading Into This Series

From 8.6:

- Security: 8.8.0 fixed CVE-2026-23479 (unblock-client use-after-free), CVE-2026-25243 (`RESTORE`), CVE-2026-23631 (Lua), CVE-2026-25588 and CVE-2026-25589 (`RESTORE` of time series and probabilistic types). 6.2.22 also carries the CVE-2026-25243 fix; check the release notes of your patch line for the others.
- Sentinel: `SENTINEL SET` config injection fixed (#14970); restrict who can run `SENTINEL SET` regardless.
- Slow log entries are truncated by the new limits; tooling that parses full arguments sees `... (N more arguments)`.
