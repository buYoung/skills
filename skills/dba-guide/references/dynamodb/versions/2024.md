# DynamoDB Service Changes in 2024

Checked: 2026-11-27 against https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/DocumentHistory.html

Read this when a design or runbook predates 2024, or when the question involves resource-based policies, on-demand maximum throughput, warm throughput, ABAC, or zero-ETL. Dates are documentation dates.

## Lifecycle

No release series; changes apply to all tables from their date. This is the oldest dated-change file kept in this reference.

## Changed Defaults

| Date | Change | What to do |
|---|---|---|
| 2024-09-03 | SDKs support account-based endpoints for DynamoDB and the `ACCOUNT_ID_ENDPOINT_MODE` setting. | Allow the account-based hostnames in egress filters, or disable the mode. Streams followed in 2026 ([2026](2026.md)). |
| 2024-05-01 | Capacity documentation restructured; the topic on switching modes moved to best practices. | No behavior change. |

## Removed or Deprecated

None documented for the service. DynamoDB local 1.25.1 (2024-11-06) is the last 1.x release in the history; 1.x is now deprecated ([local-2.x](local-2.x.md)).

## Worth Adopting

| Date | Feature | Decision it changes |
|---|---|---|
| 2024-03-20 | Resource-based policies for tables, indexes, and streams (20 KB max, Block Public Access, IAM Access Analyzer). | Grant cross-account access on the table instead of through role chaining. Required by zero-ETL to Redshift and by multi-account global tables. |
| 2024-03-19 | AWS PrivateLink interface endpoints for DynamoDB. | Private access from on-premises networks and other VPCs, in addition to gateway endpoints. |
| 2024-05-01 | Maximum throughput for on-demand tables and GSIs (`OnDemandThroughput` with `MaxReadRequestUnits`, `MaxWriteRequestUnits`). | Cap runaway on-demand cost or protect downstream systems; requests above the cap throttle with `ThrottlingException`. |
| 2024-11-13 | Warm throughput: read and write units per second a table or GSI can serve immediately, visible on every table, and increasable (pre-warming, charged). | Check before launches; pre-warm instead of synthetic load tests. Increases cannot be reversed. |
| 2024-11-18 | Attribute-based access control (ABAC) with tags on tables and indexes. | Tag-driven permissions; not supported on DynamoDB backups (use AWS Backup) and tags are not restored. |
| 2024-10-15 | Zero-ETL integration with Amazon Redshift (requires PITR and a resource-based policy; incremental replication every 15 to 30 minutes through incremental exports). | Analytics without a Streams-based pipeline. |
| 2024-12-03 | Zero-ETL integration with SageMaker Lakehouse. | Same decision for lakehouse targets. |
| 2024-12-03 | Multi-Region strong consistency for global tables first documented. | See [2025](2025.md) for the witness option and the current constraints. |
| 2024-11-12 | DynamoDB Streams consumable with Apache Flink. | Managed stream processing option. |

## Upgrading Into This Series

- Review whether cross-account access built with IAM roles should move to resource-based policies; keep one model per table to keep audits readable.
- Before enabling `OnDemandThroughput` caps, read the table's peak `ConsumedReadCapacityUnits` and `ConsumedWriteCapacityUnits` (Sum per minute divided by 60) so the cap does not throttle normal peaks. The cap is applied on a best-effort basis; burst capacity can exceed it briefly.
