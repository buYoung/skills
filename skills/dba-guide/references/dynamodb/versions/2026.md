# DynamoDB Service Changes in 2026

Checked: 2026-11-27 against https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/DocumentHistory.html

Read this when a table was designed or last reviewed before 2026, or when an answer depends on a feature documented during 2026. Dates are documentation dates from the document history.

## Lifecycle

The service has no release series. Everything below applies to every table in supported Regions from its date; nothing needs an upgrade step except a current CLI or SDK.

## Changed Defaults

| Date | Change | What to do |
|---|---|---|
| 2026-11-17 | AWS SDKs connect to DynamoDB Streams through account-based endpoints (`<account-id>.streams-ddb.<region>.amazonaws.com`, dual-stack `*.api.aws`, FIPS `streams-ddb-fips`) in the same way they already did for DynamoDB. Middle East (UAE) and Middle East (Bahrain) don't support them; the SDK for Java 1.x keeps Regional endpoints. | Before upgrading SDKs in hostname-filtered networks, allow `*.streams-ddb.<region>.amazonaws.com` (and the dual-stack or FIPS variants you use). To keep Regional endpoints, set `account_id_endpoint_mode = disabled`, `AWS_ACCOUNT_ID_ENDPOINT_MODE=disabled`, or configure only the Streams client. |
| 2026-07-01 | Documentation states that `TransactWriteItems` consumes two write units per item even when the transaction is canceled. | Size capacity and alarms for canceled transactions, not only successful ones. |
| 2026-07-01 | New `Source` dimension on `ConsumedWriteCapacityUnits` (`Customer` or `GlobalTable`). | Split your own writes from replication writes before resizing replicas. |
| 2026-07-02 | `UpdateTimeToLive` is documented as not idempotent: a `ValidationException` is returned if TTL is already enabled or if called again within one hour. | Make automation check `describe-time-to-live` first; treat that `ValidationException` as "already set". |

## Removed or Deprecated

None documented for the service in 2026. In DynamoDB local, 3.x is current; see [local-3.x](local-3.x.md).

## Worth Adopting

| Date | Feature | Decision it changes |
|---|---|---|
| 2026-11-05 | Bulk put items (`StartBulkPutItems`): load S3 data into an existing table without consuming table capacity. Standard (default, 100 GB per operation) and Accelerated (1 TB) tiers; one active operation per table; per-item condition expressions. | Use instead of hand-written `BatchWriteItem` loaders for large backfills into a live table. Without a condition expression, items overwrite existing items with the same key. |
| 2026-10-01 | Filtered export to S3: key condition, filter, and projection expressions on full and incremental exports. | Export one tenant or partition key instead of the whole table; billed on matched data with a 10 MB minimum when a key condition selects one partition key value. |
| 2026-10-20 | Disassociate an MREC global table replica while keeping its Regional table and data. | Retire a Region without deleting data; works for same-account and multi-account global tables. |
| 2026-03-18 and 2026-08-17 | Multi-account global tables: replicate between tables in different AWS accounts, with MREC or MRSC. Each replica needs a resource-based policy allowing the replication service (2026-07-10 entry). | Isolate workloads by account without building custom replication. |
| 2026-04-16 | Multi-attribute keys for GSIs: up to four attributes for the partition key and four for the sort key, declared as multiple `HASH` and `RANGE` entries in the index `KeySchema`. Queries must give equality on every partition key attribute and use sort key attributes left to right. | Stop writing synthetic concatenated GSI keys for new indexes; no backfill of composite attributes is needed. DynamoDB local supports this since 3.3.0. |
| 2026-03-18 | Proactive warm throughput increases documented; increased values cannot be decreased. | Pre-warm before launches instead of driving synthetic load; budget for the charge. |
| 2026-08-05 (filters extended 2026-11-20; quota raised 2026-10-26) | Vector indexes with `SearchVectors`: on-demand tables only, f32 storage, up to 4,096 dimensions, TopK up to 100, 16 MB responses without pagination, no FGAC, no PartiQL, counts toward the 20-GSI quota, default 5 and up to 20 per table. | Keep vector search inside DynamoDB when the limits fit; DynamoDB local ignores `VectorIndexes`, so test on the service. |
| 2026-01-13 | Cross-account Lambda triggers on a stream through resource-based policies. | Consumers in another account no longer need a relay. |
| 2026-01-29 | AWS FIS experiments on global tables, `FaultInjectionServiceInducedErrors` metric; FIS-injected 500s are counted in `SystemErrors`. | Rehearse Region isolation; separate injected errors from real ones in alarms. |
| 2026-08-19 and 2026-08-25 | ABAC and tagging for DynamoDB Streams. | Tag-based access control and cost allocation for streams. |
| 2026-10-13 and 2026-11-05 | `dynamodb:ReturnValues` condition key; `dynamodb:LeadingKeys` documented for Number (`NumericEquals`) and Binary (`BinaryEquals`, base64) partition keys. | Close the `ReturnValues` leak in attribute-level FGAC; fix FGAC policies on numeric keys that used `StringEquals`. |
| 2026-10-14 | DynamoDB Streams Kinesis Adapter can start reading from a timestamp. | Replay a window of the last 24 hours without reprocessing from `TRIM_HORIZON`. |
| 2026-11-11 | GSI creation on base tables larger than 50 TB needs allowlisting (AWS Support). | Request allowlisting before planning an index on a very large table. |
| 2026-11-18 | ExtendDB, an open-source DynamoDB-API-compatible adapter, documented for local development (`extenddb/extenddb-dev` image). | Second option next to DynamoDB local; see [dynamodb-local](../dynamodb-local.md). |

Documentation clarifications in 2026 that change advice: `Query` returning a non-empty `LastEvaluatedKey` means only that a page boundary was reached, not that more matches exist (2026-07-13); `Scan` returns partition keys in arbitrary order and items sorted by sort key within a partition key (2026-07-02); continued `Scan` across a key range can cause key-range throttling (2026-07-06); a resource-based policy with only a `Deny` can lock administrators out (2026-07-02); a KMS alias is resolved to the key ID when set (2026-07-02); Contributor Insights and deletion protection must be reconfigured after a restore (2026-07-02); GSI writes are free when an update touches no index key or projected attribute (2026-07-01).

## Upgrading Into This Series

- Upgrade the AWS CLI and SDKs before using the new parameters; older clients reject them.
- Review network egress rules before taking SDK releases with account-based Streams endpoints.
- Review FGAC policies on Number or Binary partition keys and on `ReturnValues`.

## Managed Service Notes

Multi-attribute keys and vector indexes have different support in DynamoDB local (supported since 3.3.0 and ignored, respectively). Global tables, MRSC, bulk put items, and exports do not exist in DynamoDB local.
