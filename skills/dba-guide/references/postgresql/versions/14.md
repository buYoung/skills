# PostgreSQL 14

Checked: 2026-11-27 against https://www.postgresql.org/docs/release/14.0/ and https://www.postgresql.org/support/versioning/.

Read this when the server reports `server_version_num` 140000 to 149999. 14 is end of life: use this file to plan the upgrade away from it.

## Lifecycle

- First release 14.0 on 2021-09-30. Community support ended 2026-11-12 with the final minor 14.25. No further community fixes, including security fixes.
- Amazon RDS: end of standard support 2027-02-28. Extended Support (paid) from 2027-03-01, year 3 pricing from 2029-03-01, ends 2030-02-28. RDS lists 14.25 with end of standard support "February 2028" in its minor-version table, while the major ends standard support on 2027-02-28; treat the major date as binding.
- Aurora PostgreSQL: end of standard support 2027-02-28; Extended Support until 2030-02-28; Extended Support-eligible minor 14.6 (LTS); others "to be determined" on the check date.
- Self-hosted: upgrade. If you cannot upgrade immediately, at least run 14.25.

## Changed Defaults

These are the 14 defaults that differ from 13 and still matter when you read an old configuration file:

| Setting | 13 | 14 |
| --- | --- | --- |
| `password_encryption` | `md5` | `scram-sha-256` |
| `checkpoint_completion_target` | 0.5 | 0.9 |
| `vacuum_cost_page_miss` | 10 (container 13.23) | 2 (container 14.25) |
| `VACUUM` `INDEX_CLEANUP` | `on` | `auto` (may skip index vacuuming when few dead entries) |

## Removed or Deprecated

- Version-2 wire protocol removed; SSL compression removed.
- `pg_hba.conf` `clientcert=1|0|no-verify` no longer accepted; use `verify-ca` or `verify-full`.
- `vacuum_cleanup_index_scale_factor` and `operator_precedence_warning` removed.
- Postfix operators removed; `pg_standby` removed.

## Worth Adopting

Features that exist in 14 and that the topic files assume as the baseline:

- `pg_read_all_data`, `pg_write_all_data`, `pg_database_owner` predefined roles.
- `idle_session_timeout`; `client_connection_check_interval`.
- `ALTER TABLE ... DETACH PARTITION ... CONCURRENTLY`.
- `vacuum_failsafe_age` (default 1.6 billion) makes vacuum skip index work near wraparound.
- `compute_query_id` and query IDs in `pg_stat_activity` and `EXPLAIN VERBOSE`.
- `pg_stat_wal`, `pg_stat_replication_slots`, `pg_stat_progress_copy`, `pg_backend_memory_contexts`, `pg_locks.waitstart`.
- LZ4 TOAST compression (`default_toast_compression`, default still `pglz`).
- `pg_rewind` can use a standby as the source.

What 14 lacks compared with the rest of this reference: `MERGE` (15), exclusive-backup removal (15), `pg_stat_io` (16), `EXPLAIN (GENERIC_PLAN)` (16), per-grant inheritance options (16), `pg_stat_checkpointer` and `pg_wait_events` (17), incremental backup (17), failover slots (17), logical slot preservation across pg_upgrade (source must be 17+). Container: these statements and views return errors on the 14.25 image.

## Upgrading Into This Series

Not applicable: do not upgrade into 14. Upgrade from 14 directly to 17, 18, or 19 with pg_upgrade or logical replication, reading the migration sections of 15, 16, 17, 18 (and 19 if targeted):

- [15](15.md): backup function renames, `public` schema, `stats_temp_directory`.
- [16](16.md): removed settings, role-inheritance and `CREATEROLE` changes, subscription apply as table owner; pg_upgrade refuses user-table `aclitem` columns from a 14 cluster.
- [17](17.md): `old_snapshot_threshold` removal, maintenance `search_path`; logical slots are not preserved because the source is older than 17.
- [18](18.md): checksum default mismatch with a 14 cluster (use `initdb --no-data-checksums` or enable checksums first), MD5 deprecation; statistics carried over by pg_upgrade into 18+.
- [19](19.md): pg_upgrade blockers, removed `io_workers`, JIT default.

## Managed Service Notes

- RDS and Aurora upgrades from 14 cannot keep logical replication slots; drop them (and re-create downstream CDC) before the upgrade.
- Extended Support charges begin 2027-03-01 for instances still on 14.
