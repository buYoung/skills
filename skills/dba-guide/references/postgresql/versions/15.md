# PostgreSQL 15

Checked: 2026-11-27 against https://www.postgresql.org/docs/release/15.0/ and https://www.postgresql.org/support/versioning/.

Read this when the server reports `server_version_num` 150000 to 159999, or when upgrading into 15.

## Lifecycle

- First release 15.0 on 2022-10-13; current minor 15.20; community support until 2027-11-11. This is the next series to reach end of life; plan upgrades away from it during 2027.
- Amazon RDS: end of standard support 2028-02-29; Extended Support year 1 pricing from 2028-03-01, year 3 pricing from 2030-03-01, Extended Support until 2031-02-28.
- Aurora PostgreSQL: end of standard support 2028-02-29; Extended Support until 2031-02-28; Aurora LTS minor 15.10.

## Changed Defaults

| Setting or behavior | Before 15 | 15 | Action |
| --- | --- | --- | --- |
| `CREATE` on schema `public` | granted to `PUBLIC` | not granted; schema owned by `pg_database_owner` | Applies only to new clusters and new databases. pg_upgrade and dump/restore keep old permissions, so upgraded databases still allow anyone to create in `public`: run `REVOKE CREATE ON SCHEMA public FROM PUBLIC;` deliberately. Container: 14 shows `{postgres=UC/postgres,=UC/postgres}`, 15+ shows `{pg_database_owner=UC/pg_database_owner,=U/pg_database_owner}`. |
| `hash_mem_multiplier` | 1.0 | 2.0 | Hash joins and hash aggregates may use up to `2 * work_mem` per node. Account for it in memory sizing. |
| `log_checkpoints` | off | on | Idle servers write log lines; configure rotation. |
| `log_autovacuum_min_duration` | -1 | 10min | Long autovacuum runs are logged. |
| Statistics collector | separate process, UDP, temp files | shared memory, no collector | `stats_temp_directory` removed; delete it from configs. |

## Removed or Deprecated

- Exclusive backup mode removed. `pg_start_backup()`/`pg_stop_backup()` renamed `pg_backup_start()`/`pg_backup_stop()`; `pg_backup_start_time()` and `pg_is_in_backup()` removed. Backup scripts written for 14 and older break.
- `plpython2u` and `plpythonu` removed.
- `stats_temp_directory` removed.
- `pg_dump --no-synchronized-snapshots` removed.
- Login roles lose implicit `ADMIN OPTION` on their own membership.
- Numeric literals followed directly by letters (`123abc`) are now errors.

## Worth Adopting

- `MERGE`.
- `UNIQUE NULLS NOT DISTINCT`.
- Logical replication: row filters (`WHERE`), column lists, `FOR TABLES IN SCHEMA`, two-phase commit, `ALTER SUBSCRIPTION ... SKIP`, `disable_on_error`.
- `pg_basebackup` server-side compression with gzip, LZ4, Zstandard; `wal_compression = lz4|zstd`.
- `log_destination = jsonlog`.
- `archive_library` (archive modules instead of shell `archive_command`).
- `recovery_prefetch` speeds recovery and standby replay.
- Per-database collation version tracking (`pg_database_collation_actual_version()`, `ALTER DATABASE ... REFRESH COLLATION VERSION`); warns when the OS collation library changed under existing indexes.
- `GRANT SET`/`ALTER SYSTEM` on individual parameters; `pg_checkpoint` predefined role.
- `security_invoker` views.
- `shared_memory_size` and `shared_memory_size_in_huge_pages` (read with `postgres -C` before start to size huge pages).

## Upgrading Into This Series

From 14:

- Rewrite backup scripts that call `pg_start_backup`/`pg_stop_backup` or use exclusive mode; prefer `pg_basebackup` or a tool that uses the non-exclusive API.
- Remove `stats_temp_directory` from configuration.
- Migrate `plpython2u` functions to `plpython3u` before the upgrade.
- Decide on the `public` schema `CREATE` privilege; the upgrade will not change it for you.
- Re-test memory headroom with `hash_mem_multiplier = 2`.
