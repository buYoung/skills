### 주요 (1)

#### [주요] 할인율이 배송비에도 적용됩니다

- **파일**: `pricing.py:2`
- **문제**: 새 계산식은 `subtotal_cents`와 `shipping_cents`를 먼저 더한 뒤 전체 금액에 `discount_percent`를 적용합니다. 저장소의 계약은 할인을 소계에 한 번 적용하고 배송비를 그 뒤에 더하는 것입니다.
- **근거**: `README.md`는 “Discounts apply once to the subtotal, then shipping is added.”라고 명시합니다. 인덱스의 구현을 실행한 결과 `total(1000, 500, 10)`은 `1350`을 반환했지만, 명시된 계산 순서라면 `1000 * 90 // 100 + 500 = 1400`이어야 합니다.
- **영향**: 0이 아닌 할인율을 사용하는 모든 호출에서 배송비도 같은 비율로 줄어들어 고객에게 계약보다 낮은 총액을 청구합니다. 할인율이 커질수록 과소 청구액도 증가합니다.
- **신뢰도**: High
- **제안**: 소계에만 할인을 적용한 뒤 배송비를 더하도록 계산식을 `subtotal_cents * (100 - discount_percent) // 100 + shipping_cents` 형태로 변경하고, 할인 적용 및 배송비 비할인 동작을 검증하십시오.
