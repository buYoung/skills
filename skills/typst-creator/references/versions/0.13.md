# Typst 0.13 Version Reference

Read this file for exact-version work targeting Typst 0.13.0 or 0.13.1, or for a compatibility range that includes the 0.13 line. Combine it with only the common topic references needed for the task.

## Supported Releases

| Requested target | Resolved target | Notes |
|---|---|---|
| `0.13` | `0.13.1` | Default patch for the minor line |
| `0.13.0` | `0.13.0` | Initial minor release |
| `0.13.1` | `0.13.1` | Bug-fix release |

## Added Features

- Proper paragraphs are distinct from other inline-level content. `par` show rules, `first-line-indent`, and `hanging-indent` apply to proper paragraphs.
- `par.first-line-indent` can configure whether all paragraphs are indented, not only consecutive paragraphs.
- `outline` has a new layout and entry interface; entries are blocks and expose methods for custom show rules.
- `ref` accepts `form: "page"`, `document` has a `description` field, and `enum` has a `reversed` parameter.
- `curve` supersedes the older `path` element, while `tiling` supersedes the older `pattern` name.
- `image`, `cbor`, `csv`, `json`, `toml`, `xml`, and `yaml` accept encoded `bytes` directly. Other file-backed functions also gained byte inputs where applicable.
- The first positional parameter of `image` is named `source`, not `path`; it accepts a path string or bytes in this line.
- Math function calls accept hyphenated named arguments and argument spreading.

## Behavior Changes

- Root text is collected into proper paragraphs. Inline-only content inside a container can remain unwrapped, while mixed block/inline content is collected according to the new paragraph rules.
- A bare import must have a statically determinable binding name. Rename a dynamically constructed import with `as` instead of relying on an inferred name.
- An unmatched top-level closing bracket, a space before the argument list in a set rule, and a base-prefixed number with a unit are errors.
- Single-letter quoted strings in math are no longer rendered as variables.
- `enum.number-align` defaults to `end + top` in this line. `math.cancel` defaults to `length: 100% + 3pt` and `stroke: 0.5pt`.

## Deprecated or Removed APIs

- Deprecated in 0.13: `path` in favor of `curve`; `pattern` in favor of `tiling`.
- Deprecated in 0.13: `image.decode`, `cbor.decode`, `csv.decode`, `json.decode`, `toml.decode`, `xml.decode`, and `yaml.decode`. Pass bytes to the top-level function instead.
- Deprecated in 0.13: `sect` and related symbols in favor of `inter`; use the replacement in new source because the old symbols are removed later in the supported range.
- Deprecated in 0.13: compatibility comparisons between a type and its string name, such as `int == "integer"`; this compatibility behavior is removed in 0.14.
- Removed in 0.13: the old `style` function and the `styles` argument of `measure`; use `context`.

## Generation Rules

- For new 0.13 source, use `curve`, `tiling`, `inter`, and top-level data-loading functions even though deprecated aliases may still compile.
- Spell the image parameter `source` when naming it; a positional `image("file.svg")` call is also portable.
- When writing paragraph or outline show rules, design against the 0.13 paragraph and outline models rather than pre-0.13 behavior.
- Do not use APIs introduced in 0.14 or 0.15, including `title`, `frac.style`, `page.bleed`, `divider`, `text.variations`, `within`, `list.marker-align`, or `range.inclusive`.
- For a source file that must also compile on 0.14 and 0.15, avoid `pdf.embed`: it is renamed in 0.14 and removed in 0.15, so there is no single attachment API spanning the full supported range.

## Patch Differences

- 0.13.1 adds no source-language features. It fixes high CPU use in `typst watch`, HTML table gutter export, multi-component curves, and a labelled-symbol introspection regression.
- Exact 0.13.0 output can use the same documented language surface, but verification against 0.13.0 must not be reported when only 0.13.1 was compiled.
