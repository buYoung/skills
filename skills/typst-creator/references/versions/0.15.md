# Typst 0.15 Version Reference

Read this file for exact-version work targeting Typst 0.15.0 or 0.15.1, or for a compatibility range that includes the 0.15 line. Combine it with only the common topic references needed for the task.

## Supported Releases

| Requested target | Resolved target | Notes |
|---|---|---|
| `0.15` | `0.15.1` | Default patch for the minor line |
| `0.15.0` | `0.15.0` | Initial minor release |
| `0.15.1` | `0.15.1` | Bug-fix release |

## Added Features

- The new `path` value type is accepted where file paths were represented by strings. A path remains relative to the file where it was constructed, including when passed across package boundaries.
- `divider` represents a thematic break that templates can select and style.
- Variable fonts are supported. `text.variations` configures custom variation axes; common axes are also derived from text weight, stretch, style, and size.
- `page.bleed` accepts a relative length or edge dictionary and configures bleed margins; `list.marker-align` controls list-marker alignment.
- The `within` selector matches elements contained by a selected ancestor during introspection. It is not supported as a show-rule selector. `counter.display` also has an `at` parameter.
- Dictionaries and argument values have `map` and `filter`; their callbacks receive values while dictionary keys and argument structure are preserved. `range` has an `inclusive` parameter. Additional calculation and conversion APIs include new `calc` functions and `int(base:)` string parsing.
- A document can contain multiple bibliographies, and the document/bundle APIs can emit multiple output files. These are relevant only when the task uses those model or export features.
- Spot colors and additional visualization controls are available, including `tiling.offset`.

## Behavior Changes

- File paths in Typst source cannot contain backslashes. Use forward slashes on every supported platform.
- Baseline information is retained through more boxes, blocks, equations, and list items. Existing manual alignment adjustments can produce silent layout shifts.
- `enum.number-align` defaults to horizontal `end` with the vertical component omitted so the number aligns to the item baseline.
- `math.class` applies only to its direct body instead of recursively. Math glyph stretching and `lr.size` resolution changed, and additional delimiter symbols are callable.
- The default `math.cancel` values changed to `length: 100% + 0.3em` and `stroke: 0.05em`.
- Variable-font family suffixes such as `Variable`, `Var`, and `VF` are trimmed; refer to the unified family name.
- `array.slice`, the `str` constructor, and `text.features` validate inputs more strictly.
- HTML paragraph collection and the behavior of `box` and `block` in HTML export changed. `html.script` and `html.style` accept strings rather than arbitrary content.

## Deprecated or Removed APIs

- Removed in 0.15: the old `path` drawing element; use `curve`. This is distinct from the new `path` value type for file paths.
- Removed in 0.15: the `pattern` type; use `tiling`.
- Removed in 0.15: `pdf.embed`; use `pdf.attach`.
- Removed in 0.15: `image.decode`, `cbor.decode`, `csv.decode`, `json.decode`, `toml.decode`, `xml.decode`, and `yaml.decode`; pass bytes to top-level functions.
- Removed in 0.15: previously deprecated symbols, including old names documented by the official symbol changelog.
- Deprecated in 0.15: numbering systems silently falling back to Arabic numerals for zero and ambiguous raw language-tag spellings.

## Generation Rules

- Use `path` only as a file-path value. Use `curve` for drawing and explain the distinction when migrating older source.
- Use `divider`, `text.variations`, `page.bleed`, `list.marker-align`, introspection-only `selector.within`, collection `map`/`filter`, and `range.inclusive` only for targets at least 0.15.0.
- Omit `Variable`, `Var`, or `VF` suffixes from variable-font family names.
- Use forward slashes in imports, includes, images, bibliographies, and other paths.
- Recheck baselines and math spacing when migrating a layout from 0.14 or earlier; successful compilation does not prove identical rendering.
- For range-compatible output extending back to 0.13, use `curve`, `tiling`, top-level data-loading functions, and avoid all 0.15-only APIs.

## Patch Differences

- 0.15.1 adds no new source-language feature for this skill. It fixes regressions in math alignment inside `lr`, `math.op` vertical alignment, multi-page list alignment, bundle watch-server content types, and related export behavior.
- New Computer Modern 8.1.1 in 0.15.1 fixes the regular math font's calligraphic-letterform behavior. Rendering can differ from 0.15.0 even when source compiles under both.
- Verification against 0.15.1 does not prove identical output under 0.15.0; report the compiler actually used.
