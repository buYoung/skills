# Typst 0.14 Version Reference

Read this file for exact-version work targeting Typst 0.14.0, 0.14.1, or 0.14.2, or for a compatibility range that crosses the 0.14 line. Combine it with only the common topic references needed for the task.

## Supported Releases

| Requested target | Resolved target | Notes |
|---|---|---|
| `0.14` | `0.14.2` | Default and security-fixed patch |
| `0.14.0` | `0.14.0` | Initial minor release |
| `0.14.1` | `0.14.1` | Bug-fix release affected by the plugin runtime issue fixed in 0.14.2 |
| `0.14.2` | `0.14.2` | Security and diagnostics release |

## Added Features

- PDF export is tagged for accessibility by default and can target PDF/UA-1, all PDF/A standards, and additional PDF versions through compiler options.
- `title` is a document element, and tables can contain multiple headers and subheaders.
- `frac.style` supports `"vertical"`, `"skewed"`, and `"horizontal"` layouts. `math.equation.alt` can provide an alternative equation description.
- `par.justification-limits` enables character-level justification. PDF and WebP files can be used as image sources.
- Typed HTML element functions such as `html.div` are available alongside `html.elem`; this remains export-target-specific source.
- `pdf.attach` replaces the `pdf.embed` name for PDF attachments.
- Scripting additions include module membership checks with `in`, `default` parameters on selected array/string methods, `array.sorted(by:)`, and `str.normalize`.
- More elements, including paragraphs, tables, lists, titles, figures, and images, are locatable without labels.

## Behavior Changes

- PDF export was rewritten. Visual or structural output can change even when the Typst source is unchanged; recheck accessibility, links, tagging, and image handling.
- Empty labels are errors.
- An empty `text.font` list is an error, and 0.14 warns that variable fonts are not yet supported.
- Type/string compatibility comparisons deprecated in 0.13 are no longer accepted.
- `toml` is guaranteed to return a dictionary and `toml.encode` requires a dictionary.
- `enum.number-align` still defaults to `end + top`. `math.cancel` still defaults to `length: 100% + 3pt` and `stroke: 0.5pt`.

## Deprecated or Removed APIs

- Deprecated in 0.14: `pdf.embed` in favor of `pdf.attach`; the alias is removed in 0.15.
- Deprecated in 0.14: `--make-deps` in favor of `--deps --deps-format make`.
- Removed in 0.14: compatibility comparisons such as `int == "integer"`; compare against types directly.
- The 0.13 deprecations for `path`, `pattern`, scoped `.decode` functions, and renamed symbols still matter because they are removed in 0.15.

## Generation Rules

- Prefer 0.14.2 when the target is given only as `0.14`.
- Use `pdf.attach` for exact 0.14 output that needs attachments. Do not use it for a range including 0.13, and do not use `pdf.embed` for a range including 0.15.
- Use `title`, `frac.style`, typed HTML, PDF-as-image, and the new scripting parameters only when the resolved target is at least 0.14.0.
- Do not use 0.15-only APIs such as `path` values, `divider`, variable-font `text.variations`, `page.bleed`, `list.marker-align`, `within`, dictionary `map`/`filter`, or `range.inclusive`.
- When plugins are involved, warn that 0.14.0 and 0.14.1 use an affected WebAssembly runtime and recommend 0.14.2. Do not claim that source changes mitigate the runtime issue.

## Patch Differences

- 0.14.1 is a bug-fix release for PDF, HTML, math, model, text, and other regressions; it does not add a new source-language surface for this skill.
- 0.14.2 updates the WebAssembly runtime to fix a memory-handling vulnerability present in 0.14.0 and 0.14.1 and adds a sorting diagnostic hint. Typst 0.13.1 and below are not affected by that vulnerability.
- Verification against 0.14.2 does not prove identical rendering under 0.14.0 or 0.14.1; report the compiler actually used.
