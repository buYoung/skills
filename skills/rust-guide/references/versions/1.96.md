# Rust 1.96

Released 2026-05-28; point release 1.96.1 on 2026-06-30.

## Deprecations and Removals

- None. The new `core::range::{Range, RangeFrom, RangeInclusive, RangeToInclusive}` types are stable, but `a..b` syntax keeps producing `std::ops::Range`; the switch is planned for a future edition, so no code change is needed now.

## Migration Instructions

- WebAssembly targets no longer pass `--allow-undefined` to the linker, so an undefined symbol is a link error instead of silently becoming an import from the `env` module. Where those imports are intentional, restore the old behavior with `RUSTFLAGS=-Clink-arg=--allow-undefined` while making the imports explicit.
- Security: CVE-2026-5223 (extracting crate tarballs containing symlinks) and CVE-2026-5222 (authentication using normalized URLs) affect users of third-party registries; crates.io users are stated as unaffected. Users of alternative registries should update.

## Behavior Changes Requiring Attention

- 1.96.1 adds missing retries and timeouts to Cargo's HTTP client, fixes a miscompilation in a MIR optimization, and updates the bundled `libssh2` for CVE-2025-15661, CVE-2026-55199, and CVE-2026-55200. Prefer 1.96.1 over 1.96.0.

## Replacement APIs Worth Adopting

- `assert_matches!` and `debug_assert_matches!` (imported explicitly; not in the prelude because of name clashes with third-party crates); `From<T> for LazyLock<T, F>` and `LazyCell`; `From<T> for AssertUnwindSafe<T>`.
