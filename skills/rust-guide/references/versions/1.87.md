# Rust 1.87

## Deprecations and Removals

- The `i586-pc-windows-msvc` target is removed; use `i686-pc-windows-msvc`.
- `std::env::home_dir` is undeprecated after the 1.85.0 behavior fix. Remove `#[allow(deprecated)]` and replacement-crate workarounds that existed only because of the deprecation, if the fixed semantics are acceptable.

## Migration Instructions

- Most `std::arch` intrinsics that take no pointer arguments are callable from safe code when the caller has the target feature enabled. Existing `unsafe {}` blocks around them now trigger `unused_unsafe`; remove the blocks that are no longer needed rather than allowing the lint.

## Behavior Changes Requiring Attention

- None beyond the safe-intrinsics change above.

## Replacement APIs Worth Adopting

- `use<..>` precise capturing on `impl Trait` returns inside trait definitions.
- `asm!` may jump to labeled Rust blocks (`asm_goto`).
- `std::io::pipe` anonymous pipes integrated with `Command`; `Vec::extract_if`, `LinkedList::extract_if`; `<[T]>::split_off_first`, `split_off_last`, `split_off`; `String::extend_from_within`; `OsStr::display`; `is_multiple_of`, `cast_signed`, `cast_unsigned`, `unbounded_shl`, `unbounded_shr`.
