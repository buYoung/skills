# Rust 1.90

## Deprecations and Removals

- `x86_64-apple-darwin` is demoted from Tier 1 to Tier 2 with host tools. Builds stay available through `rustup`; automated test coverage for the target decreases over time.
- Tier 3 `musl` targets link dynamically by default.

## Migration Instructions

- `lld` is the default linker on `x86_64-unknown-linux-gnu`. If a linker script, plugin, or build depends on GNU `ld` behavior, opt out with `-C linker-features=-lld` while fixing the dependency.
- `UnixStream` writes set `MSG_NOSIGNAL`; a program that relied on receiving `SIGPIPE` when the peer closed must handle the resulting write error instead.
- Unsupported `extern "{abi}"` strings are rejected consistently in every position; correct any ABI string that only compiled in some positions.

## Behavior Changes Requiring Attention

- On Unix, `std::env::home_dir` falls back to the user database when `HOME` is set but empty.
- `core::iter::Fuse`'s `Default` impl constructs `I::default()` internally; writes during static initialization are errors in const evaluation.

## Replacement APIs Worth Adopting

- `cargo publish --workspace` publishes members in dependency order and verifies all of them in a dry run.
- `checked_sub_signed`, `overflowing_sub_signed`, `saturating_sub_signed`, `wrapping_sub_signed` on unsigned integers; const `<[T]>::reverse` and const float `floor`, `ceil`, `trunc`, `round`.
