# Rust 1.92

Released 2025-12-11.

## Deprecations and Removals

None.

## Migration Instructions

- `never_type_fallback_flowing_into_unsafe` and `dependency_on_unit_never_type_fallback` are deny-by-default. Where inference relied on `!` falling back to `()` (a `?` in a generic call, a diverging closure passed where a `Default`-returning type was expected), write the intended type explicitly. `#[allow]` is possible but only postpones the edition 2024 behavior.
- `invalid_macro_export_arguments` is deny-by-default and reported in dependencies too; fix invalid `#[macro_export]` arguments.

## Behavior Changes Requiring Attention

- With `-C panic=abort` on Linux, unwind tables are emitted by default so backtraces work again. Builds that want the smaller output back set `-C force-unwind-tables=no`.
- `unused_must_use` no longer fires on `Result<(), UninhabitedType>` or `ControlFlow<UninhabitedType, ()>`.

## Replacement APIs Worth Adopting

- `RwLockWriteGuard::downgrade` to move from a write lock to a read lock without releasing; `Box::new_zeroed`, `Rc::new_zeroed`, `Arc::new_zeroed` and their `_slice` forms; `btree_map::Entry::insert_entry`; `NonZero::div_ceil`; const `<[T]>::rotate_left`, `rotate_right`.
