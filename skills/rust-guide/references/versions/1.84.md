# Rust 1.84

Released 2025-01-09; point release 1.84.1 on 2025-01-30.

## Deprecations and Removals

- The `wasm32-wasi` target is removed. Build with `wasm32-wasip1`, the same target under its current name.

## Migration Instructions

- The MSRV-aware dependency resolver is stable. Opt in with `resolver = "3"` in `[package]` or `[workspace]` (understood by Cargo 1.84 and later), or in `.cargo/config.toml` with `[resolver] incompatible-rust-versions = "fallback"`. Edition 2024 makes it the default; a virtual workspace must set it explicitly in `[workspace]`.
- Replace pointer-to-integer round trips with the strict-provenance APIs: `ptr.addr()`, `with_addr`, `map_addr`, `expose_provenance`, `ptr::with_exposed_provenance`, `ptr::without_provenance`, `ptr::dangling`.

## Behavior Changes Requiring Attention

- Coherence checking uses the next-generation trait solver and may report "conflicting implementations of trait" errors that earlier releases missed; such errors are real and need a fix, not a workaround.
- 1.84.1 fixes an internal compiler error, spurious overlapping-impl errors in incremental builds, and slow compilation caused by the new solver.

## Replacement APIs Worth Adopting

- `isqrt` on integers, `Ipv6Addr::is_unique_local`, `Ipv6Addr::is_unicast_link_local`, `Pin::as_deref_mut`.
