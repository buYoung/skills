# Rust 1.80

## Deprecations and Removals

None.

## Migration Instructions

- Cargo now always passes `--check-cfg`, so the warn-by-default `unexpected_cfgs` lint fires on every custom `cfg` that is not declared. Declare custom cfgs instead of allowing the lint: in a build script, `println!("cargo::rustc-check-cfg=cfg(loom)");` or in `Cargo.toml`, `[lints.rust] unexpected_cfgs = { level = "warn", check-cfg = ['cfg(loom)'] }`.
- Exclusive range patterns come with the `non_contiguous_range_endpoints` and `overlapping_range_endpoints` lints; fix the gaps or overlaps they point at rather than allowing them.

## Behavior Changes Requiring Attention

- The prelude now exports `size_of`, `size_of_val`, `align_of`, and `align_of_val`; a local function with one of these names shadows the prelude item and can make existing call sites ambiguous or misleading.
- `Box<[T]>` implements `IntoIterator` by value. `for x in boxed_slice` yields `T` in every edition; `boxed_slice.into_iter()` keeps yielding `&T` until edition 2024 (see [1.85](1.85.md)).
- 1.80.1 fixes a miscompilation of floating-point equality comparisons introduced by a jump-threading optimization in 1.78.0 and reverts `dead_code` changes that produced false positives. Do not pin 1.80.0.

## Replacement APIs Worth Adopting

- `std::sync::LazyLock` and `std::cell::LazyCell` replace `lazy_static!` and `once_cell::sync::Lazy` for lazily initialized statics and thread-locals once the MSRV allows.
- Exclusive range patterns `a..b` in `match`; `Option::take_if`; `<[T]>::split_at_checked`; `trim_ascii`.
