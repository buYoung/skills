# Rust 1.88

## Deprecations and Removals

- The libtest flag `--nocapture` is deprecated in favor of `--no-capture`; update CI invocations.
- `#[bench]` without `#![feature(custom_test_frameworks)]` is a hard error (it was a deny-by-default future-incompatibility lint since 1.77). Move benchmarks to a stable harness such as `criterion` or `divan`.
- `i686-pc-windows-gnu` is demoted from Tier 1 to Tier 2; toolchains remain available through `rustup`.

## Migration Instructions

- Cargo's automatic garbage collection of the global cache is on by default: files that need a network download are deleted after 3 months without access and files that can be regenerated without the network after 1 month. If a Cargo older than 1.78 shares the same `CARGO_HOME`, set `cache.auto-clean-frequency = "never"` in its configuration.
- `dangerous_implicit_autorefs` (warn; deny in [1.89](1.89.md)) flags an implicit autoref through a raw-pointer dereference such as `(*ptr).field.len()`; take an explicit reference or copy the value instead.
- `invalid_null_arguments` (uplifted from Clippy) flags null pointers passed to functions that require non-null arguments.

## Behavior Changes Requiring Attention

- `{float}::NAN` is guaranteed to be a quiet NaN.
- Proc macros can no longer observe `cfg(true)` attributes after expansion.
- `-C dwarf-version` is stable for selecting the DWARF version of debug info.

## Replacement APIs Worth Adopting

- `let` chains in `if` and `while` conditions (edition 2024 only); `cfg(true)` and `cfg(false)` instead of `cfg(all())` and `cfg(any())`; `#[unsafe(naked)]` functions with `naked_asm!`.
- `Cell::update`; `HashMap::extract_if`, `HashSet::extract_if`; `<[T]>::as_chunks`, `as_rchunks`; `hint::select_unpredictable`; `proc_macro::Span::{line, column, file}`.
