# Rust 1.97

## Deprecations and Removals

- The legacy symbol mangling scheme is no longer the default and is available only on nightly, with eventual removal announced. The v0 scheme (`_R...` symbols, opt-in since 1.59 via `-C symbol-mangling-version=v0`) is the default on stable.

## Migration Instructions

- Update tooling that parses legacy `_ZN...` mangled names (symbolizers, custom profilers, allowlists in crash reporting) to understand v0 names.
- The new `linker_messages` lint (warn-by-default, not part of the `warnings` group) surfaces linker stderr that a successful link used to hide. Read each message; when one is known and harmless, silence it per crate with `[lints.rust] linker_messages = "allow"` in `Cargo.toml`.
- CI that wants warnings to fail the build can set `CARGO_BUILD_WARNINGS=deny`; the variable accepts `allow`, `warn` (default), and `deny` and does not invalidate the build cache.

## Behavior Changes Requiring Attention

- 1.97.1 fixes an LLVM miscompilation present since at least 1.87 that 1.97.0's IR changes made more likely to trigger. Prefer 1.97.1 over 1.97.0.

## Replacement APIs Worth Adopting

- `isolate_highest_one`, `isolate_lowest_one`, `highest_one`, `lowest_one`, `bit_width` on integers and `NonZero`; const `char::is_control`.
