# Rust 1.86

## Deprecations and Removals

- The Tier 2 target `i586-pc-windows-msvc` is announced for removal in 1.87.0. Move builds to `i686-pc-windows-msvc`.

## Migration Instructions

- `missing_abi` is now warn-by-default: `extern fn` and `extern { ... }` without an ABI string must say `extern "C"` (or the intended ABI) explicitly.

## Behavior Changes Requiring Attention

- With debug assertions enabled, the compiler inserts runtime checks that pointers are non-null on reads, writes, and reborrows. Debug builds may now panic where release builds continue; the release states this is not a soundness guarantee.

## Replacement APIs Worth Adopting

- Trait upcasting (`&dyn Sub` to `&dyn Super`, also through `Box`, `Rc`, `Arc`) removes hand-written `as_super()` helper methods.
- `#[target_feature(enable = "...")]` on safe functions; calling one from a context without the feature still requires `unsafe`.
- `HashMap::get_disjoint_mut` and `<[T]>::get_disjoint_mut` replace `split_at_mut` arithmetic or `unsafe` for several simultaneous mutable borrows; `Vec::pop_if`; `Once::wait`, `OnceLock::wait`; `f32::next_up`/`next_down`.
