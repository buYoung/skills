# Rust 1.91

Released 2025-10-30; point release 1.91.1 on 2025-11-10.

## Deprecations and Removals

- `target_env = "macabi"` and `target_env = "sim"` cfgs are added as replacements for the `target_abi` cfgs with the same values.

## Migration Instructions

- `semicolon_in_expressions_from_macros` is deny-by-default and will become a hard error: fix `macro_rules!` macros used in expression position that expand to a trailing `;`. The lint was already a future-compatibility warning reported in dependencies.
- New warn-by-default lints: `dangling_pointers_from_locals` (returning a raw pointer to a local variable) and `integer_to_ptr_transmutes` (integer-to-pointer transmutes; use `ptr::with_exposed_provenance` or `without_provenance`).

## Behavior Changes Requiring Attention

- Pattern bindings are lowered in the order they are written and drop order follows the primary bindings' order; code that depended on the previous drop order of bindings in one pattern can change behavior.
- Panic messages now include the thread ID; update log parsers that match the message format.
- `std::thread::Builder::stack_size` failures return an error from `spawn` instead of panicking inside the standard library.
- The parameter order passed to the `_by` closures of `min_by`, `max_by`, and `minmax_by` in `std::cmp` is guaranteed.
- `cargo publish` no longer emits `.crate` files as a final artifact when `build.build-dir` is set; the release notes state this will apply regardless of `build.build-dir` in a future version. Scripts should take the packaged file from `cargo package` output rather than assuming `target/package`.
- 1.91.1 fixes a regression in `#[link(wasm_import_module)]` that could link the wrong function when the same symbol is imported from different Wasm modules, and fixes Cargo's target-directory locking on illumos.

## Replacement APIs Worth Adopting

- C-style variadic functions may be declared (not defined) in `extern` blocks for the `sysv64`, `win64`, `efiapi`, and `aapcs` ABIs.
- `Path::file_prefix`; `PathBuf::add_extension`, `with_added_extension`; `str::floor_char_boundary`, `ceil_char_boundary`; `BTreeMap::extract_if`, `BTreeSet::extract_if`; `Duration::from_mins`, `from_hours`; `strict_*` and `carrying_*` integer arithmetic; `AtomicPtr::fetch_ptr_add` and bitwise `fetch_*`; `core::iter::chain`; `core::array::repeat`; `PanicHookInfo::payload_as_str`.
- Cargo: `build.build-dir` separates intermediate artifacts from the final `target` layout; `--target host-tuple` is accepted. Targets: `aarch64-pc-windows-msvc` Tier 1; `aarch64-pc-windows-gnullvm` and `x86_64-pc-windows-gnullvm` Tier 2 with host tools.
