# Rust 1.82

## Deprecations and Removals

None formally deprecated. The release introduces the syntax that edition 2024 later requires: non-`unsafe` `extern` blocks and unwrapped `#[no_mangle]`, `#[export_name]`, and `#[link_section]` attributes become errors in edition 2024 (`missing_unsafe_on_extern`, `unsafe_attr_outside_unsafe` lints).

## Migration Instructions

- Use `&raw const place` and `&raw mut place` instead of `std::ptr::addr_of!` and `addr_of_mut!`; the new syntax needs no `unsafe` block even for a `static mut` and handles misaligned or dangling places correctly.
- Write foreign declarations as `unsafe extern { ... }`; mark an item `safe fn` only when calling it is sound with any arguments, because the block author takes on that obligation.
- Wrap the attributes as `#[unsafe(no_mangle)]`, `#[unsafe(export_name = "...")]`, and `#[unsafe(link_section = "...")]` ahead of the edition switch.

```rust
#[repr(C, packed)]
struct Packet {
    tag: u8,
    payload: u32, // misaligned: a plain `&packet.payload` is a compile error
}

fn payload_ptr(packet: &Packet) -> *const u32 {
    // Before: std::ptr::addr_of!(packet.payload)
    &raw const packet.payload
}

// Before: `extern "C" { ... }` and `#[no_mangle]`; both are errors in edition 2024.
unsafe extern "C" {
    fn getpid() -> i32;
    safe fn abs(value: i32) -> i32; // sound for any argument, so callers need no unsafe block
}

#[unsafe(no_mangle)]
pub extern "C" fn plugin_abi_version() -> u32 {
    3
}

fn current_pid() -> i32 {
    // SAFETY: getpid has no preconditions.
    unsafe { getpid() }
}

fn magnitude(value: i32) -> i32 {
    abs(value)
}
```

## Behavior Changes Requiring Attention

- Floating-point operations that produce NaN are allowed in `const` contexts; NaN sign and payload bits are unspecified everywhere, so code must not depend on them.
- Match arms for uninhabited types can be omitted (`let Ok(x) = infallible_result;`); these patterns are deliberately not yet reported as unreachable.

## Replacement APIs Worth Adopting

- `use<..>` precise capturing on `impl Trait` returns in free functions and inherent methods replaces the `Captures` trick.
- `Option::is_none_or`, `<[T]>::is_sorted` and variants, `iter::repeat_n`, `Box::new_uninit`, `Rc::new_uninit`, `Arc::new_uninit`.
- Cargo: `cargo info <crate>`. Targets: `aarch64-apple-darwin` Tier 1; Mac Catalyst targets Tier 2.
